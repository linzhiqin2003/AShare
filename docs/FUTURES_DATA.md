# 境内期货数据

覆盖中金所、上期所、大商所、郑商所、上期能源（INE）、广期所六个交易所能取到的全部日频历史。设计见 `docs/DESIGN.md` 6.1.1。本文是字段口径、各交易所差异、已知数据问题和校验结果；数字都来自 2026-11-13 在开发数据根上的全量下载（截至交易日 2026-11-12）。

## 最短例子

```bash
# 采集（默认 1995-04-17 至昨天；断点续跑，重跑只补没完成的分区和最近 5 个交易日）
python -m ashare.data --root /path/to/root sync-futures
python -m ashare.data --root /path/to/root build-futures   # 构建「交易日 × 合约」面板
python -m ashare.data --root /path/to/root verify-futures  # 独立校验，报告在 <root>/cn/reports/futures_verify.md
```

```python
import ashare.data as ad
import panelbt as bt
from ashare.data.futures_panelbt import panelbt_inputs

fut = ad.open("/path/to/root").futures()
fut.contracts(products=["SC"]).collect()                        # 合约表
p = fut.panel(["settlement", "open_interest"], products=["SC"], start="2024-01-02")
p.dates, p.symbols, p["settlement"]                             # T×N 只读数组
sc = fut.continuous("SC", rule="open_interest", adjust="ratio") # 主力连续（比例后复权）
rolls = fut.roll_schedule("SC", rule="open_interest")           # 换月日程表

inputs = panelbt_inputs(fut, products=["IF"], start="2024-01-02", end="2024-12-31")
market = bt.Market(**inputs["market"], futures=inputs["futures"])
```

数据根：开发与验证写在 `data/dev/futures/`（`open` 的 root 指向它，实际文件在 `<root>/cn/`）；正式库只是把 root 换成 `data/`，期货数据集与股票共用一份清单，但各自成目录，股票的同步、校验、面板版本都不受影响。

## 统一字段

来源无关，定义在 `ashare.data.futures_schema`，`describe()` 打出完整表。合约标识写成「品种 + 四位年月 + . + 交易所全称」：`SC2612.INE`、`RB2701.SHFE`、`TA2611.CZCE`、`IF2612.CFFEX`；大商所月均价合约写成 `L_F2605.DCE`。日期一律是 `YYYYMMDD` 字符串，交易所交易日口径。

### 合约表 `contracts`

| 字段 | 单位 / 取值 | 时点 | Tushare 来源 |
|---|---|---|---|
| symbol | 统一合约标识 | 挂牌前公布 | ts_code 改写 |
| exchange、product | 交易所全称；品种代码大写 | 静态 | 代码后缀；fut_code |
| name | 名称 | 静态 | name |
| listing_date | 首个交易日 | 挂牌前公布 | list_date |
| last_trade_date | 最后交易日 | 挂牌前公布 | delist_date |
| delivery_date | 最后交割日（可空） | 挂牌前公布 | last_ddate |
| delivery_month | YYYYMM（可空） | 静态 | d_month |
| multiplier | 每手对应的报价单位数量 | 挂牌前公布 | 见下「合约乘数」 |
| quote_unit | 报价单位（元/吨、指数点…） | 静态 | quote_unit |
| tick_size | 最小变动价位，报价单位 | 挂牌前公布 | quote_unit_desc 的数字部分 |
| settlement_type | physical / cash | 静态 | d_mode_desc |
| currency | CNY | 静态 | — |
| multiplier_source | contract_table / implied_from_amount | 静态 | — |

### 日线 `daily`（面板同名字段）

| 字段 | 单位 | 时点 |
|---|---|---|
| open、high、low、close | 报价单位；有夜盘的品种，开盘价是前一晚夜盘的集合竞价价，高低价含夜盘 | 交易日日盘收盘后 |
| settlement | 报价单位；逐日盯市所用的当日结算价（见「结算价口径」） | 结算后 |
| previous_settlement | 报价单位；上一交易日结算价，新合约首日为挂牌基准价 | 盘前 |
| volume | 手，**单边** | 收盘后 |
| amount | 元，单边 | 收盘后 |
| open_interest | 手，单边 | 收盘后 |

### 逐日参数 `params`（面板同名字段，按「交易日 × 合约」存，同一品种不同月份可以不同）

| 字段 | 单位 | 时点 |
|---|---|---|
| margin_long、margin_short | 比例；交易所买 / 卖投机保证金率 | 当日结算所用（新标准常在执行前一交易日结算时已生效） |
| hedge_margin_long、hedge_margin_short | 比例；套保保证金率 | 同上 |
| fee_open_rate、fee_open_per_contract | 比例；元/手。两种收费方式一个为 0 | 同上 |
| fee_close_rate、fee_close_per_contract | 平昨仓，交易所标准与开仓相同 | 同上 |
| fee_close_today_rate、fee_close_today_per_contract | 平今仓；**源缺失为空，不代表免收** | 同上 |
| delivery_fee_rate、delivery_fee_per_contract | 交割手续费；只换算了上期所 / 能源中心的比例部分，其余为空 | 同上 |
| price_limit | 涨跌停幅度；Tushare 没有，恒为空。以后取交易所每日交易参数文件（上期所 `ContractDailyTradeArgument`） | 盘前 |

面板另有 `has_quote`（当天有日线）和 `is_listed`（上市日到最后交易日，含两端）。

费用都是**交易所标准**，不含期货公司加收（调研：公示标准约为交易所 3 倍，保证金加 4–7 个百分点），回测里用 `panelbt_inputs(fee_scale=...)` 或显式参数自己加。

### 合约乘数

- 股指、国债期货（中金所）和集运指数（INE EC）用 `fut_basic.multiplier`，其余商品用 `per_unit`（交易单位/手）。商品的 `multiplier` 一列是空的，误用会差 10–1000 倍。
- 报价单位与交易单位不一致时换算：鸡蛋（JD）交易单位 5 吨、报价「元/500 千克」，每手 = 10 个报价单位。
- 合约表的交易单位是**现值**；历史上改过交易单位的品种，旧合约要按「成交额 ÷ (成交量 × 结算价)」反查（每个合约取中位数，与合约表相差 2% 以上就用反查值并标 `implied_from_amount`）。全历史实测到的（品种、年份、中位比值）：橡胶 RU 2008–2011 为 0.5（旧合约 5 吨）、铅 PB 2011–2013 为 5（旧合约 25 吨）、燃料油 FU 2012–2017 为 5（旧合约 50 吨）、纤维板 FB 2013–2019 为 50（旧合约 500 张，现为 10 立方米）、鸡蛋 JD 全程 2（报价单位换算，已在合约表一层处理）。其余品种 1720527 行里 96.9% 的单行比值在 ±2% 内。

### 来源的主力映射 `mapping`（可选表）

`date`、`continuous`（来源的连续代码，如 `SC.INE`）、`kind`（`main` 主力 / `nearby` 连续近月）、`symbol`。注意 `AL.SHF`、`TL.CFX` 本身就是品种：判断 kind 看被映射合约的品种，不看代码末尾的 L。

## 境外来源适配器的接口约定

一个适配器是有五个方法的对象：`contracts()`、`daily()`、`params()`、`calendar()`，可选 `mapping()`，以及可选的 `source_continuous()`（来源自带的连续合约，只用于对账）。每个方法返回 polars DataFrame，列名、类型、单位严格按上面的统一字段，交给 `futures_schema.conform(name, frame)` 检查（缺必填列或有多余列直接报错）。`build_futures(store, adapter)` 只调用这些方法。

- **必填**：contracts 的 symbol、exchange、product、listing_date、last_trade_date、multiplier、currency；daily 的 date、symbol、open、high、low、close、settlement、previous_settlement、volume；params 的 date、symbol、margin_long、margin_short；calendar 全部三列。其余可空。
- 境外合约标识：`CL2612.NYMEX`、`B2612.ICE`，currency 写 USD。价格保持来源报价单位（美元/桶），multiplier = 1000（桶/手）。
- 境外日线的 `date` 用交易所自己的交易日（CME Globex 的周日晚开盘归周一）；`settlement` 用交易所公布的结算价（ICE Brent 是 19:28–19:30 伦敦时间加权，CME 是 14:28–14:30 纽约时间），不要用收盘价。
- 保证金和费用没有交易所逐日参数时，params 只交 margin（可以是经纪商标准，写明来源），费用列留空，回测里显式传。
- 成交量、持仓量一律单边。

## 交易所之间的口径差异

| 项目 | 中金所 | 上期所 / 能源中心 | 大商所 | 郑商所 | 广期所 |
|---|---|---|---|---|---|
| Tushare 代码后缀 | .CFX | .SHF / .INE | .DCE | .ZCE | .GFE |
| 交易所原生代码 | 大写 IF2612 | 小写 cu2612 | 小写 m2701 | 大写**三位年月** TA611 | 小写 lc2701 |
| Tushare `fut_basic.symbol` | IF2612 | CU2612 | M2701 | **TA611**（ts_code 是四位 TA2611） | LC2701 |
| 成交量 / 持仓量 / 成交额 | 始终单边 | **2020-01-02 前双边**，之后单边 | 同左 | 同左 | 始终单边（2022-12-22 起） |
| 保证金率单位（fut_settle） | **百分数**（12 = 12%） | 小数（0.2 = 20%） | 小数 | 小数 | 小数 |
| 手续费（fut_settle） | trading_fee_rate 与 trading_fee 填**同一个数**：股指是万分之几，国债是元/手 | trading_fee_rate 是**千分之几**、trading_fee 是元/手，二者分开 | 只有 trading_fee，同一列既有元/手又有万分之几，**源里没有标记** | 只有 trading_fee，元/手 | 同大商所 |
| 平今费（offset_today_fee） | 相对普通费的**百分比**（1000 = 10 倍，0 = 免收） | **源里为空** | 与 trading_fee 同口径 | 元/手 | 同大商所 |
| 结算参数覆盖起点 | 2011-01-21 | **2021-01-04** | 2011-01-04 | 2011-01-04 | 2023-01-03 |
| 结算价 | 最后一小时成交量加权；到期日为交割结算价（指数最后两小时算术平均） | 全天成交量加权 | 全天成交量加权 | 全天成交量加权 | 全天成交量加权 |

单边双边的依据：双边计数时每笔成交买卖各记一次，成交量和持仓量恒为偶数。上期所、大商所、郑商所、能源中心 2019-12-31 及以前全部行（几十万行）的成交量和持仓量都是偶数，2020-01-02 起奇数约占一半；中金所、广期所任何年份奇数都约占一半。成交额与成交量同口径（反查乘数的中位比值在切换前后都是 1），统一字段把三者一起除以 2。

费率单位的核对（交易日 2026-11-12，对照交易所每日结算参数文件，调研见主目录 `docs/markets/futures_rules.md`）：SC 20 元/手 ✓，sc2612、sc2701 投机保证金 20%、套保 19%，远月 16% ✓；LU 0.01 → 万分之 0.1 ✓；FU 活跃月 0.05 → 万分之 0.5、其余 0.01 → 万分之 0.1 ✓；EC 0.6 → 万分之 6、交割费 0.02 → 万分之 0.2 ✓；CU 0.05 → 万分之 0.5 ✓；IF 0.23 → 万分之 0.23，平今 1000% → 万分之 2.3 ✓（华金期货价目表，旁证）。SC 平今 10 元/手在交易所文件里有，Tushare 为空 ✗。

大商所、广期所按金额收费的品种（`futures_tushare.RATE_BASED`）：大商所 I、J、JM、JD、BB、FB、LH，广期所 SI、LC、PS；按手：大商所 A、B、C、CS、EB、EG、L、M、P、PG、PP、RR、V、Y 及月均价合约。这张表是交易所现行标准（据经验整理，大商所、广期所官网对本环境返回 412 未能核对原文），历史上改过收费方式的未核实；不在表里的品种（大商所 LG、BZ，广期所 PT、PD）费用留空。

## 交易日与夜盘

- 交易日从前一个工作日夜盘开始到当天日盘结束：周五夜盘归下周一，节假日前一晚通常不开夜盘。Tushare 日线按交易所交易日给，T 日的开盘价是 T−1 晚夜盘集合竞价价，最高最低价含夜盘。本数据不建模夜盘，只按交易日口径存。
- 期货面板的主日历是六个交易所开市日的并集。2000 年以后各交易所不一致的日子只有 8 天：大商所 2000-01-31 至 02-02 休市、郑商所和大商所 2001-01-31 至 02-02 休市、郑商所 2001-12-29、30（周末补班日）休市，其余交易所开市。
- 与股票（上交所）日历比较（2000-01-01 至 2026-11-12）：期货有、股票没有的 15 天（上面 8 天，加 2002-02-19 至 22、2002-09-28、2006-01-26、27 的春节或国庆调休），股票有、期货没有的 2 天（2001-12-31、2002-01-04）；2006 年以后完全一致。所以期货一律用期货交易所自己的日历，不借用股票日历。

## 换月规则与连续合约

- `rule="source"`：照 Tushare `fut_mapping` 的主力映射。只有主力。
- `rule="open_interest"` / `"volume"`：第 t 日的选择只读第 t−1 日的指标和第 t 日的可选集合（第 t−1 日有行情、最后交易日晚于第 t 日）。主力：当前合约仍可选时，只有指标最大的候选到期更晚、且指标严格大于当前合约才换；当前合约不可选（快到期）时强制换到更晚合约里指标最大的。次主力：在到期晚于当天主力的可选合约里用同样规则。不在最后交易日当天新进入，也不持有到最后交易日当天。
- 复权：换月日 r 取旧、新两个合约当天的价格（缺一个就用两者都有的最近一天）。差值后复权在之后每段加累计价差 Σ(旧−新)，比例后复权乘累计比值 Π(旧/新)，第一段是真实价格；换月日的连续价格等于旧合约当天价格，即当天涨跌归旧合约、按换月日结算价换月。
- 换月日程表 `roll_schedule`：date（新合约开始的日子）、from_symbol、to_symbol、price_date、from_price、to_price、spread（新−旧）。回测按它逐个合约持有和换月，连续价格只算信号。

### Tushare 主力切换规则（由数据反推）

全部 6183 次主力切换：

- 向后（换到更晚到期的合约）5934 次，**向前回切 249 次**（集中在 2000 年前后的早期数据和流动性差的品种，例如 `A.DCE` 2001-12-29 从 A0209 回到 A0205）。
- 新主力是前一交易日持仓量最大的合约：5377 次（87%）；是当天持仓量最大的：5348 次；前一日新合约持仓量大于旧合约：5499 / 6139 次（90%）。用当天数据（前视）判定反而对得更少，看不出 Tushare 用了当天收盘后的信息。
- 在旧合约最后交易日当天换的 618 次，最后交易日之后才换的 45 次（旧合约已不再交易仍被映射）。
- 结论：Tushare 主力大致是「前一日持仓量最大、多数只向后」，但有回切、等持仓也换、到期后才换等反例，不是一条可以完全复现的规则。对照下面五个品种，自判规则与它逐日持有同一合约的比例在 79%–99%。

### 五个品种主力连续对账

`rule="source"` 拼出的不调整主力连续，与 Tushare 自带的主力连续日线（`SC.INE` 等代码，在 `fut_daily` 里）逐日比较结算价和收盘价：

| 品种 | 对账区间 | 天数 | 结算价不符 | 收盘价不符 | 只在一边有的日子 | 来源换月次数 | 持仓规则逐日同一合约 | 成交量规则逐日同一合约 | 持仓规则换月与来源同一天 / 早 1 天 / 相差更多 |
|---|---|---|---|---|---|---|---|---|---|
| SC | 2018-03-26–2026-11-12 | 2095 | 0 | 0 | 0 | 96 | 87.0% | 96.6% | 21 / 10 / 64 |
| RB | 2009-03-27–2026-11-12 | 4283 | 0 | 0 | 0 | 56 | 99.0% | 98.2% | 38 / 4 / 14 |
| IF | 2010-04-16–2026-11-12 | 4025 | 0 | 0 | 0 | 182 | 78.8% | 97.0% | 104 / 2 / 35 |
| M | 2000-07-17–2026-11-12 | 6391 | 0 | 0 | 0 | 86 | 94.1% | 85.9% | 62 / 0 / 22 |
| TA | 2006-12-18–2026-11-12 | 4835 | 0 | 0 | 0 | 70 | 99.0% | 96.4% | 52 / 5 / 13 |

- Tushare 的主力连续就是被映射合约当天的原始价格（不复权），与映射逐日一致，没有需要解释的差异。
- 自判规则与来源的差异全部来自换月时点：SC、IF 这类近月最活跃的品种，来源与「成交量」规则更接近（96.6%、97.0%），说明来源在这些品种上更看成交量或按临近到期换；RB、TA 持仓规则几乎一致。「相差更多」的换月里自判规则多数更早（持仓量提前转移到下一合约）。
- 「早 1 天」的个数远多于「晚 1 天」（0），与「来源用前一日数据、换月当天才生效」一致。

## 结算价口径（到期日）

最后交易日的结算价是不是交割结算价，按「是否落在最小变动价位网格上」判断（交割结算价是平均值，一般不在网格上）：

| 交易所 | 平日结算价在网格上 | 最后交易日在网格上 | 结论 |
|---|---|---|---|
| 中金所股指（IF/IH/IC/IM） | 99.9% | 5%–10% | 最后交易日给的是**交割结算价**（指数最后两小时算术平均），可以直接作 panelbt 的到期行结算价 |
| 中金所国债 | 69%–100% | 同平日 | 普通结算价；交割按交割结算价另算，未提供 |
| 上期所、能源中心、大商所、郑商所、广期所 | 93%–100% | 同平日 | 普通结算价；交割结算价（大商所等为交割月结算价的加权平均）不在源里，实物交割品种不应持有到期 |
