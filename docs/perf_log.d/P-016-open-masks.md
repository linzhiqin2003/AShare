### P-016 开盘可买、可卖掩码由数据层预先算好

- 提交：（待填）
- 手段：数学（少算）。回测行情准备每次都从 6 个面板字段（开、高、低、涨停价、跌停价、停牌 | 无行情）用 numpy 现算 `can_buy/can_sell`；改为建面板时逐行算好存成两个 1 字节布尔字段，回测直接读。
- 新字段（写入 `catalog.FIELDS`、元数据字段说明、`verify`）：
  - `can_buy_open`：当日以开盘价成交能否买入。
  - `can_sell_open`：当日以开盘价成交能否卖出。
  - 口径与 `panelbt.markets.ashare.tradability(open, high, low, upper_limit, lower_limit, is_suspended | ~has_quote)` 逐格相同（即 `bench/e2e/stage_backtest.market_inputs` 现在的算法）：
    - 有效 = 开盘价有限且 > 0，且不是 `is_suspended`，且 `has_quote`；未上市、退市后、无行情的格开盘价为 NaN 或 `has_quote` 为假，自然不可交易。
    - 不能买：涨停价有限且开盘价 ≥ 涨停价 − 0.005；或一字板（最高、最低都有限且相差 ≤ 0.005）且最高价 ≥ 涨停价 − 0.005。
    - 不能卖：跌停价有限且开盘价 ≤ 跌停价 + 0.005；或一字板且最低价 ≤ 跌停价 + 0.005。
    - 涨跌停价缺失视为该方向无限制。容差 0.005 元与 `panelbt.markets.ashare.PRICE_TOL` 相同，测试守住两者相等。
  - 构建用数据层自己的实现（`ashare/data/panel_trade.py`，进入代码哈希）；`verify` 用 panelbt 的函数按年重算逐格比对（检查名 `open_masks_match_panelbt`），两边口径一旦分叉就会报出。
- 现有口径里留给负责人定的疑问（照搬，未改）：
  1. 一字板用当日最高最低价判断，这两个价收盘后才知道；作为回测成交约束可以，作为盘前信号就是前视。字段说明里已写明。
  2. `tradable`（has_quote 且 volume>0）与这里不一致：有行情但成交量为 0 的格这里算可交易。
  3. 容差是绝对 0.005 元，不随价格档位变化；北交所、低价股的最小价位都是 0.01，问题不大，但若以后有 0.001 价位的品种需要复核。
  4. 开盘价 ≥ 涨停价 − 容差即判不能买，而不区分「开盘涨停后打开」的情形（开盘那一刻确实买不到，口径合理）。
- 回测适配（`bench/e2e/stage_backtest.market_inputs`）：面板里有这两个字段就直接读，没有（旧面板）时照旧现算，口径相同；`run` 取字段时自动带上。
