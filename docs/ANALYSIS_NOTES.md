## 最短用法

```python
import numpy as np
import panelbt
import ashare.data
import ashare.analysis as an

panel = an.LazyPanel(ashare.data.open(), start="20130104")       # 按需读字段
market = an.market_from_panel(panel)
config = an.ashare_config(panel.symbols, record_trades=True)
result = panelbt.run(market, targets, an.default_costs(panel.dates), config)

held = np.nan_to_num(result.positions) != 0
columns = an.held_columns(held, panel["weight_csi300"], symbols=panel.symbols)
history = an.FactorHistory.build(panel, columns=columns, cache=".cache/risk")

report = an.attribute(result, panel, history, benchmark="000300.SH", start="20150105")
risk = an.risk_series(result, panel, history, benchmark="000300.SH", start="20150105")
sectors = an.brinson(result, panel, "000300.SH", start="20150105")
cap = an.capacity(targets, panel, aum=[1e7, 1e8, 1e9, 1e10], benchmark="000300.SH", rerun=True)
costs = an.cost_breakdown(result, panel.dates, start="20150105")
report.to_dict()       # 列式、只含 JSON 基本类型
```

## 口径

### 时间

- `weights[t]` 是第 t 日收盘后的权重，赚第 t+1 日的收益；`Result` 的权重 = 持仓股数 × 收盘价
  （缺价沿用最近有效值，与 panelbt 估值一致）÷ 当日权益。
- 第 t 日的归因用 t-1 收盘的持仓、暴露 `B_{t-1}`、行业分类和基准权重，乘 t 日的收益
  （t-1 收盘到 t 收盘的总收益，按复权因子）。没有任何量用到 t 日收盘以后的信息。
- 因子收益 `f_t`：由 `FactorHistory` 在遍历 `ashare.risk.model_series` 时补算，用风险模型自己的
  截面回归内核和估计池规则（t-1 日上市满 60 天、未停牌、市值有效，权重 sqrt(市值)，行业收益
  按市值加权和为零），因此与风险模型内部的因子收益逐位相同（测试用 monkeypatch 截获核对）。
- 基准：数据层的指数权重是月末快照、下一交易日起可用。新快照出现那天直接用它；两份快照之间
  按成分股收益漂移（不漂移等于每天按快照再平衡，不是指数的真实持仓）。

### 收益归因的六项

逐日：`市场 + 行业 + 风格 + 特质 + 交易 + 成本 = Rp − Rb`。

- 市场、行业、风格：主动暴露 `x = B_{t-1}ᵀ(h_p − h_b)` 乘因子收益，按因子名分类
  （`country` 为市场、`industry_*` 为行业、其余为风格）。
- 特质：持仓主动收益减去因子解释的部分。`diagnostics` 里另给组合侧与基准侧的拆分。
- 交易：`Rp − 持仓收益 + 成本率`。包括调仓日成交价与收盘价之差、挂单重试日的成交、现金利息，
  以及 panelbt 按面板事件记分红送转、这里按复权因子算收益的细小差异（见「已知局限」）。
- 成本：佣金、税、过户费、滑点、冲击、融券费之和 ÷ (E[t-1] + 资金流)，即 panelbt 收益的分母。

### 多期链接

累计主动收益定义为算术差 `Π(1+Rp) − Π(1+Rb)`。默认 GRAP：`C_T = C_{T-1}(1+Rb_T) + a_T·Π_{s<T}(1+Rp_s)`。
选它的理由：不取对数、没有除法，组合与基准收益相等时没有奇点；一次递推就得到每一天的累计值；
各项之和与累计主动收益在数学上逐项伸缩相消，数值误差只有累加的舍入。缺点是同样大小的贡献发生在
不同日子权重不同（复利本身如此）。可选 Carino（`method="carino"`）：与顺序无关，但要取对数。

### 风险归因

Euler 拆分：因子 k 的方差贡献 `x_k (F x)_k`，特质 `Σ D a²`，各项之和为 σ²；除以 σ 是对波动率的贡献，
和为 σ。因子间协方差平分到两边，不单列交叉项。边际贡献 `(F x)_k / σ`（因子）与 `(B F x + D a)_i / σ`
（个股）。逐日序列第 t 行用 t 日收盘后的权重和 t 日模型，预测 t+1 日的持仓主动收益；偏差统计量
`std(实现 / 预测)`，近似 95% 区间 `1 ± sqrt(2/n)`。

### Brinson

Brinson-Fachler 默认，BHB 可选；选择项 `Wb (Rp_s − Rb_s)`、交互项 `(Wp − Wb)(Rp_s − Rb_s)`。
现金单列一个行业、收益两边都确定为 0，现金拖累全部记在现金一行的配置项（BF；BHB 下现金配置项为 0）。
组合在某行业没有持仓时取 `Rp_s = Rb_s`；基准没有某行业时取 `Rb_s = Rb`（BF 下配置为 0，超额进交互）。

### 容量与成本

- 冲击模型与 panelbt 同一公式：成交价 `p(1 ± slippage)(1 ± k·(q/V)^e)`，冲击成本 `q·|p_e − p_s|`。
  默认 `e = 0.5`，`k = 1 × 此前 20 日的日收益标准差`（只用 t-1 及以前的数据；缺失用当日截面中位数）。
- 解析模拟 `simulate`：按股数记的现金账户，目标股数按开盘估值的权益算，先卖后买，买单超过现金时
  同比例缩小，不能买卖的挂单逐日重试到下次调仓，送转、派现、退市照面板事件处理。与 panelbt 的区别
  只有两点：不取整、不设成交量占比上限。所以 panelbt 用同样两条宽松规则时，两者逐笔相等（见对账表）。
- 容量一：年化总成本 = `cost_fraction`（默认 0.5）× 年化毛超额收益时的规模。毛超额 = 同一规则下全部
  成本为零时的年化收益 − 基准持仓的年化收益；毛超额 ≤ 0 记 0；固定费用已经超过一半时记搜索下限 1 万元。
- 容量二：成交量占比超过 `participation_cap`（10%）的成交额占全部成交额的比例达到 `breach_share`（5%）
  时的规模。按成交额而不是按笔数加权，因为笔数会被大量很小的调整主导。
- 两种容量都在对数刻度上先扫 19 个点再二分 40 次（每次一遍解析模拟）。
- 变现天数：每次调仓后的持仓按「10% × 此前 20 日平均成交额」每天卖，需要几天。此前 20 日没有成交额的
  持仓卖不出，单列 `share_no_volume`。

### 与 `ashare.report` 的口径对照

| 量 | 本包 | 报告模块 | 说明 |
|---|---|---|---|
| 年化 | 252 个交易日 | 252 | 相同 |
| 换手 | `turnover`、`annual_turnover` 为双边；另给 `turnover_one_sided` | `daily.turnover`、`annual_turnover` 为双边 | 相同 |
| 成本率 | 每日成本 ÷ 前一日权益（+ 资金流），再按年相加 | 年度拆解：全年费用 ÷ 上年末权益 | **有意不同**：逐日分母反映每笔费用占当时资金的比例；年内净值变化不大时两者几乎相同，大涨大跌的年份有差别 |
| 滑点与冲击 | 分开两列 | 合在 `slippage` 里 | 容量分析只关心冲击，所以分开 |
| 比例 | 小数 | 小数 | 相同 |
| 缺失值 | `to_dict()` 里 NaN、inf 记为 `null` | 同 | 相同 |
| 键名 | 英文小写下划线；行名列叫 `date`、`aum`、`year`、`sector`、`factor`、`group`、`symbol` | 列式 | 以后作为可选小节接入 |

## 真实数据例子：沪深 300 内低波动 30 只、月度调仓

运行 `python -m ashare.analysis.example`。面板从 2013-01-04 起（风险模型的描述子需要约一年历史），
归因区间 2015-01-05 至 2026-11-12，共 2881 个交易日。

策略：每月第一个交易日开盘成交。信号只用前一交易日收盘及以前的数据：在当天的沪深 300 成分里，
取此前 60 个交易日日收益标准差最小的 30 只，等权，合计 99%。初始资金 1000 万元，按 A 股整手成交，
用默认成本（佣金万 2.5、最低 5 元，过户费，滑点万 5，印花税按日期）。基准是沪深 300 的持仓收益
（月末快照，快照之间按成分股收益漂移）。

第一次跑时发现例子本身有错：停牌日价格不动、收益为 0，长期停牌的股票被当成「低波动」选了进来。
变现表里有 8% 的持仓此前 20 日成交额为 0，这个问题由此暴露。修正后只用有行情、未停牌的交易日
计算波动率，并排除信号日停牌的股票。下面全是修正后重跑的结果。

平均主动暴露（绝对值最大的几项）：账面市值比 +1.42，贝塔 −1.24，流动性 −0.99，盈利市值比 +0.99，

这正是低波动组合应有的样子：低贝塔、低换手的大盘价值股，残差波动为负。由于风险模型里残差波动
已经对贝塔和市值做过正交，低波动的主要暴露落在贝塔上。

**特质项为什么是很大的负数。** 第一次（有错的那轮）特质项累计 −86%，修正后为 −45%，而累计主动收益是
+41%。逐项查过：

1. **链接放大了绝对值，但没有改变符号。** 不链接的逐日算术和：特质 −26.7%，主动收益 +13.1%。
   GRAP 把第 t 天的贡献乘以此前组合的累计增长（这个组合 11.9 年涨了 92%），所以每一项的绝对值都放大
   约 1.7 倍，因子项也一样。Carino 给出的数几乎相同（特质 −43.7%）。放大是复利本身的结果，不是链接方法
   单独针对特质项造成的。
2. **组合侧与基准侧。** 逐日算术和里，组合持仓自身的特质收益是 −21.2%，基准持仓的特质收益是 +5.5%
   （相减后为 −26.7%）。约八成来自组合这边：低波动的股票在风格解释之外，长期每年约跑输 2%。
3. **因子项与特质项在相互抵消。** 三类因子的链接合计是 +106%，特质 −45%。逐日看，因子贡献合计与特质
   贡献的相关系数是 −0.25。在这个只选 30 只大盘低波股、并且重仓银行的组合上，截面回归把一部分收益在
   「风格」和「特质」之间分得并不稳定。
4. **换估计池或回归权重后的变化（逐日算术和）：**

   | 回归设定 | 市场 | 行业 | 风格 | 特质 | 因子与特质的日相关 |
   |---|---|---|---|---|---|
   | 默认（全市场估计池，权重 sqrt(市值)） | −0.038 | +0.217 | +0.325 | −0.267 | −0.25 |
   | 只用沪深 300 成分做估计池 | −0.034 | +0.282 | +0.239 | −0.250 | −0.31 |
   | 市值加权（权重 = 市值） | −0.016 | +0.203 | +0.458 | −0.409 | −0.27 |

   市值加权时，回归更贴合大盘股：风格多拿了 13 个百分点，特质相应少了 14 个百分点。只用沪深 300 做
   估计池时，行业和风格之间挪了约 7 个百分点，特质变化不大。也就是说，「风格 + 特质」的合计是稳的，
   两者之间的分界取决于回归设定，十二年里差 ±15 个百分点，约合每年 1 个多百分点。
5. **独立核对。** 在真实数据 2020 年初的 30 个交易日上，用逐股、逐因子循环的参考实现
   （`test/analysis/analysis_reference.py`）重算同一组输入，各项最大差 2.7e-17；
   不在保存列里的持仓权重为 0（3e-16）。数字本身算得没错。

**使用者该怎么读这个数。** 特质项是「风险模型的风格解释不了的部分」，它与风格项是一对此消彼长的量。
这个低波组合靠价值、低贝塔等风格赚钱，同时在这些风格之外每年约跑输 2%。结论要看「风格 + 特质」的
合计与逐年数字，不要单独解读一个十几年的链接累计值：链接会按组合的增长放大每一项，而风格与特质的
分界会随回归设定移动一到两个百分点每年。

交易项累计 −5.9%，其中约 −2.4%（逐日算术和）来自调仓日开盘成交价与收盘价之差和挂单重试日的成交。
没有任何成交的 2635 天里，交易项 11.9 年合计只有 +0.06%（单日最大 3.9 bp）：这是 panelbt 按面板事件记
分红送转、这里按复权因子算收益的差异，集中在除权除息日。例如 2015-05-26 有两只股票的参考价口径
相差 0.1%。

### 风险归因

日频跟踪误差平均 0.88%（年化约 14%）。平均占比：风格 73%，行业 16%，特质 9%，市场 1.5%。

偏差统计量（全样本 2880 天）为 0.964，略低于 95% 区间 [0.974, 1.026]：风险模型对这个组合的跟踪误差
略有高估。252 日滚动窗口的平均值为 0.95，其中 53% 的窗口落在区间外。这些窗口互相重叠，不是独立样本。

## 验证

- **参考实现**（`test/analysis/analysis_reference.py`）：逐日、逐股、逐因子的纯 Python 循环，不调用本包任何代码。
  - 收益归因的各项对拍，包括风险模型没覆盖的证券、某天没有因子收益两个分支。
  - GRAP 与 Carino 的期末值：参考实现用直接公式，不用递推。
  - Brinson 各行业三项，包括组合或基准缺某个行业、现金一行。
  - 风险：在稠密协方差 `BFBᵀ + D` 下算组合风险与个股贡献，对拍。
  - 单笔成交的五项成本。
  - 真实数据：抽 2020 年初 30 个交易日，用同一个循环参考实现核对收益归因的逐日每一项，最大差 2.7e-17。
- **恒等式**：收益、风险、Brinson 三处，逐日与累计都测。
- **已知答案**：
  - 只暴露一个风格因子的组合：其余各项都低于 1e-15。
  - 与基准完全相同的组合：各项恰为 0。
  - 只有行业之间配比不同的组合：选择与交互低于 1e-16。
  - 组合留 10% 现金、其余与基准同比例：配置项每天恰为 −10% × 基准收益。
  - 按风险模型真实生成收益时，偏差统计量落在 95% 区间内。
- **Brinson 教科书例子**：Carl Bacon《Practical Portfolio Performance Measurement and Attribution》中的三国例子。
  组合权重 40/30/30%、基准 40/20/40%；组合收益 20/−5/6%、基准收益 10/−4/8%；组合 8.3%、基准 6.4%。
  Brinson-Fachler 配置 0/−1.04/−0.16%，选择 4/−0.2/−0.8%，交互 0/−0.1/0.2%，合计 1.9%。
  数值为按该书方法手算，图表编号未核对。
- **因子收益**：与风险模型内部的回归逐位相同；与独立的 numpy 加权最小二乘（`ashare.risk.kernels.cross_section`）
  相差在 1e-9 以内；改动 t+1 日以后的价格，≤ t 日的因子收益不变。
- **容量对账**：合成数据含停牌挂单、送转、派现、退市和买单按现金缩放。在这上面，解析模拟与 panelbt
  （不取整、无上限）逐笔相等：各项成本相对误差在 1e-9 以内，期末权益在 1e-10 以内。真实数据上的对账见上表。
- **结果转 dict**：所有结果对象的 `to_dict()` 都能用 `json.dumps(..., allow_nan=False)` 序列化。

全市场的暴露约 7 GB，放不进内存。测这一项时用一个按块返回同一块暴露的对象代替：计算量和访存方式

  向量化代码。

## 已知局限

- 暴露只保存组合与基准出现过的证券（`columns`），不把全市场十五年的暴露整体放进内存；截面回归仍用当天的全部证券。
- 解析容量不做整手、不设成交量上限。真实规则下的差别，看 `rerun=True` 的并排表。
- 交易项里混有 panelbt 按面板事件记分红送转、这里按复权因子算收益的差异。真实例子里，没有成交的日子
  11.9 年合计约 0.06%。
- 风格与特质的分界取决于风险模型的回归设定，见上面的调查。分析结论应该看「风格 + 特质」的合计和逐年数字。
- 基准用持仓收益（月末快照加漂移），不是指数点位。快照之间的成分调整和指数自身的计算细节，会让它与指数
  涨跌有小的差别。
- 风险模型对这个低波组合的跟踪误差略有高估（偏差统计量 0.964）；暂时只报告，不在本包里校正。
