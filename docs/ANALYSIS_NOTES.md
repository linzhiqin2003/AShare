# 归因与容量（`ashare.analysis`）实现笔记

设计见 `docs/DESIGN.md` 6.5。本文是口径、真实数据上的例子、验证记录和性能数字。

## 最短用法

```python
import numpy as np
import panelbt
import ashare.data
import ashare.analysis as an
from ashare.backtest import execution_targets, market_from_panel

data = ashare.data.open()
panel = an.LazyPanel(data, start="20130104")                     # 按需读字段
signal = ...                       # T×N，第 t 行是第 t 日收盘后算出的目标权重，整行 NaN = 不调仓
targets = execution_targets(signal)                               # 移到下一交易日成交
bm = market_from_panel(data, start="20130104")                    # 行情、整手规则、历史费率
result = panelbt.run(bm.market, targets, bm.costs(), bm.config(record_trades=True))

held = np.nan_to_num(result.positions) != 0
columns = an.held_columns(held, panel["weight_csi300"], symbols=panel.symbols)
history = an.FactorHistory.build(panel, columns=columns, cache=".cache/risk")

report = an.attribute(result, panel, history, benchmark="000300.SH", start="20150105")
risk = an.risk_series(result, panel, history, benchmark="000300.SH", start="20150105")
sectors = an.brinson(result, panel, "000300.SH", start="20150105")
cap = an.capacity(targets, panel, aum=[1e7, 1e8, 1e9, 1e10], benchmark="000300.SH",
                  rerun=True, market=bm.market, costs=bm.costs())
costs = an.cost_breakdown(result, panel.dates, start="20150105")
report.to_dict()                    # 列式、只含 JSON 基本类型；不带诊断
report.to_dict(diagnostics=True)    # 另加 diagnostics 一节（逐日数组）
```

`held_columns` 一定要把基准权重一起传进去：只给组合的列时，基准成分没有暴露，它们的收益会整笔
落进特质项（`attribute` 在未覆盖的主动权重日均超过 2% 时告警，见下文）。

完整可运行的例子：`python -m ashare.analysis.example`（下文的表都由它生成）。

## 口径

### 时间

- `weights[t]` 是第 t 日收盘后的权重，赚第 t+1 日的收益；`Result` 的权重 = 持仓股数 × 估值价 ÷ 当日权益。
  估值价与 panelbt 内核相同（`reference_close`）：有收盘价用收盘价，停牌缺价时用最近收盘价，之后每遇
  派现减去每股派现、每遇送转除以送转比例（同一天先派现后送转）。持仓市值加现金与 panelbt 的权益逐日
  相等（真实例子最大相对差 4.4e-16）。
- 个股收益：后复权价 `close × adj_factor` 作为一个整体沿用最近有效值，再取比值。停牌日收益为 0，停牌
  期间的除权日也是 0，复牌日的收益 = 复牌收盘 ÷ 除权参考价 − 1。收盘价和复权因子不能分开沿用：
  那样停牌中的除权日会出现一笔假收益、复牌日再反向（例如 002657.SZ 2015-03-20 +100%、03-23 −45%）。
  主干 `ashare.risk.data.adjusted_returns` 用同一个后复权价，但停牌缺价记 NaN（风险模型估计因子收益时
  要剔除停牌）；这里要的是持仓的估值收益，所以沿用。
- 第 t 日的归因用 t-1 收盘的持仓、暴露 `B_{t-1}`、行业分类和基准权重，乘 t 日的收益
  （t-1 收盘到 t 收盘的总收益，按复权因子）。没有任何量用到 t 日收盘以后的信息。
- 因子收益 `f_t`：由 `FactorHistory` 在遍历 `ashare.risk.model_series` 时补算，用风险模型自己的
  截面回归内核和估计池规则（t-1 日上市满 60 天、未停牌、市值有效，权重 sqrt(市值)，行业收益
  按市值加权和为零），因此与风险模型内部的因子收益逐位相同（测试用 monkeypatch 截获核对）。
- 基准：数据层的指数权重是月末快照、下一交易日起可用。新快照出现那天直接用它；两份快照之间
  按成分股收益漂移（不漂移等于每天按快照再平衡，不是指数的真实持仓）。`risk_series` 第 t 行用第
  t+1 行的基准权重作为 t 日收盘后的基准，也依赖「快照下一交易日起可用」这条约定（代码里有注释）。

### 收益归因的六项

逐日：`市场 + 行业 + 风格 + 特质 + 交易 + 成本 = Rp − Rb`。

- 市场、行业、风格：主动暴露 `x = B_{t-1}ᵀ(h_p − h_b)` 乘因子收益，按因子名分类
  （`country` 为市场、`industry_*` 为行业、其余为风格）。
- 特质：持仓主动收益减去因子解释的部分。`diagnostics` 里另给几项逐日拆分（单利）：组合侧与基准侧；
  未覆盖证券（没有暴露）的部分 `uncovered_specific`；停牌持仓的部分 `suspended_specific`。停牌日收益
  为 0，但因子项按暴露照算，差额 `a·(0 − B·f)` 落在特质项。分解本身不改（停牌股票确实没有赚到因子
  收益），只把这部分单列出来。
- 交易：`Rp − 持仓收益 + 成本率`。包括调仓日成交价与收盘价之差、挂单重试日的成交、现金利息，以及
  派现日的口径差异：持仓收益按复权因子算（分红再投资），引擎把分红记成现金。这部分逐日单列在诊断
  `dividend_convention`（`Σ h · (现金口径收益 − 复权因子口径收益)`，现金口径见 `cash_returns`）里，
  没有成交的日子交易项恰好等于它。
- 成本：佣金、税、过户费、滑点、冲击、融券费、红利税、融资利息之和 ÷ (E[t-1] + 资金流)，即 panelbt
  收益的分母。
- 未覆盖告警：风险历史没有覆盖的主动权重（逐日绝对值之和）日均超过 `max_uncovered`（默认 2%）时
  发 `UserWarning`。默认值的依据：真实例子里新股和缺描述子的证券造成的未覆盖权重为 0（沪深 300
  成分几乎都有暴露），2% 只拦「漏了基准列」这种量级的错误（合成数据上漏列时日均 50% 以上）。

### 多期链接

累计主动收益定义为算术差 `Π(1+Rp) − Π(1+Rb)`。默认 GRAP：`C_T = C_{T-1}(1+Rb_T) + a_T·Π_{s<T}(1+Rp_s)`。
选它的理由：不取对数、没有除法，组合与基准收益相等时没有奇点；一次递推就得到每一天的累计值；
各项之和与累计主动收益在数学上逐项伸缩相消，数值误差只有累加的舍入。缺点是同样大小的贡献发生在
不同日子权重不同（复利本身如此）。可选 Carino（`method="carino"`）：与顺序无关，但要取对数。

### 风险归因

Euler 拆分：因子 k 的方差贡献 `x_k (F x)_k`，特质 `Σ D a²`，各项之和为 σ²；除以 σ 是对波动率的贡献，
和为 σ。因子间协方差平分到两边，不单列交叉项。边际贡献 `(F x)_k / σ`（因子）与 `(B F x + D a)_i / σ`
（个股）。逐日序列第 t 行用 t 日收盘后的权重和 t 日模型，预测 t+1 日的持仓主动收益；偏差统计量
`std(实现 / 预测)`。区间是「模型准确时统计量的 95% 范围」，给三种：默认 `interval` 用 20 日一块的移动
块自助法（2000 次，固定种子；把自助样本除以统计量本身移到 1 附近），它同时照顾厚尾和波动聚集；
`interval_kurtosis` 按样本峰度修正 `1 ± 1.96·sqrt((κ−1)/(4n))`；`interval_normal` 是正态下的
`1 ± sqrt(2/n)`。真实数据的 z 峰度约 4，正态区间偏窄。

### Brinson

Brinson-Fachler 默认，BHB 可选；选择项 `Wb (Rp_s − Rb_s)`、交互项 `(Wp − Wb)(Rp_s − Rb_s)`。
现金单列一个行业、收益两边都确定为 0，现金拖累全部记在现金一行的配置项（BF；BHB 下现金配置项为 0）。
组合在某行业没有持仓时取 `Rp_s = Rb_s`；基准没有某行业时取 `Rb_s = Rb`（BF 下配置为 0，超额进交互）。

### 容量与成本

- 冲击模型与 panelbt 同一公式：成交价 `p(1 ± slippage)(1 ± k·(q/V)^e)`，冲击成本 `q·|p_e − p_s|`。
  默认 `e = 0.5`，`k = 1 × 此前 20 日的日收益标准差`（只用 t-1 及以前的数据；缺失用当日截面中位数）。
- 费用：默认用主干的 A 股费用表 `ASHARE.costs`（佣金万 2.5、最低 5 元，滑点万 5，按日期的印花税和过户费，
  含按股收取的过户费）。
- 解析模拟 `simulate_many`（`simulate` 是单个规模的写法）：按股数记的现金账户，目标股数按开盘估值的权益算，先卖后买，买单超过现金时
  同比例缩小，不能买卖的挂单逐日重试到下次调仓，送转、派现、退市照面板事件处理，停牌持仓按除权参考价
  估值。与 panelbt 的区别只有两点：不取整、不设成交量占比上限。所以 panelbt 用同样两条宽松规则时，
  两者逐笔相等（见对账表）。多个规模的账户互不影响，只是逐日一起推进（数组多一个规模维），所以一次算
  几十个规模与算一个规模的耗时同一量级；与逐个单独模拟相比只差浮点舍入（测试守在 1e-12）。
- 容量一（`by_cost`）：成本曲线先降后升。小规模时最低佣金 5 元这样的固定费用占比很高，规模变大后冲击
  占主导。做法：在 `search`（默认 1 万到 10 万亿元）的对数网格上每十倍取 5 个点，找成本最低点
  （`min_cost_aum`、`min_cost`）；从它往大规模方向找第一次越过 `cost_fraction × 毛超额` 的网格区间，
  区间里的交点就是容量；往小规模方向的交点另报为最小可行规模 `min_viable_aum`。毛超额 = 同一规则下全部
  成本为零时的年化收益 − 基准持仓的年化收益。
- 求交点用成批的多分法：每一轮在每个未收敛的区间里取 `points`（默认 15）个对数等距的内点，几个区间的
  候选规模合成一批模拟，区间每轮缩小 16 倍，直到区间两端之比小于 `1 + rtol`（默认 1e-6），返回越过门槛
  的那一端。一个网格格子跨 0.2 个十倍，5 轮收敛。整个求解是：表里的规模加 46 个网格点一批，三个交点的
  多分法 5 批，另有一次全部成本为零的模拟算毛收益。网格密度没有降低（每十倍 5 个点）；测试用每十倍
  40 个点的细网格核对，粗网格找到的最低成本不比它高 2% 以上。
- 资金小到最低佣金等固定费用把账户打穿（某个成交日前的权益或期末权益 ≤ 0）：这种规模的成本记为无穷大
  （不参与找最低点）；出现在容量表里时，成本率、扣成本后超额记 NaN，
  `wiped_out` 列为 1。
- 容量二（`by_participation`）：成交量占比超过 `participation_cap`（10%）的成交额占全部成交额的比例
  **超过** `breach_share`（5%）时的最小规模。按成交额而不是按笔数加权，因为笔数会被大量很小的调整主导。
  `breach_share = 0` 表示「出现任何一笔超限成交」。
- 每个容量都带状态字段（`by_cost_status`、`min_viable_status`、`by_participation_status`）：`found`；
  `no_gross_excess`（毛超额 ≤ 0，值为 NaN）；`never_viable`（最低成本也超过门槛，NaN）；
  `beyond_search_range`（到搜索上限也没越过，inf）；`below_search_floor`（搜索下限处已经越过，NaN；
  对 `min_viable_aum` 表示在下限处固定费用也不构成约束）。任何情况下都不拿搜索边界充当结果。
- `rerun=True` 的并排表里，`real_fill_ratio` 是真实规则下的换手合计 ÷ 宽松规则下的换手合计，即目标交易
  全期最终成交了多少。两次运行的权益路径不同，它是近似，可以略大于 1（真实例子 1 亿时 1.0007）；
  panelbt 的诊断里没有逐笔的目标股数，拿不到「实际成交股数 ÷ 目标成交股数」；`real_blocked_orders` 是真实规则下
  被拦下的买单与卖单数（每只证券每天算一次，挂单重试会重复计数），不是天数。
- 变现天数：每次调仓后的持仓按「10% × 此前 20 日平均成交额」每天卖，需要几天。此前 20 日没有成交额的
  持仓卖不出，单列 `share_no_volume`。

### 与 `ashare.report` 的口径对照

| 量 | 本包 | 报告模块 | 说明 |
|---|---|---|---|
| 年化 | 252 个交易日 | 252 | 相同 |
| 换手 | `turnover`、`annual_turnover` 为双边；另给 `turnover_one_sided` | `daily.turnover`、`annual_turnover` 为双边 | 相同 |
| 成本率 | 每日成本 ÷ 前一日权益（+ 资金流），再按年相加 | 年度拆解：全年费用 ÷ 上年末权益 | **有意不同**：逐日分母反映每笔费用占当时资金的比例；年内净值变化不大时两者几乎相同，大涨大跌的年份有差别 |
| 成本项 | 佣金、印花税、其他费用、滑点、冲击、融券费、红利税、融资利息 | 见 `REPORT_NOTES.md` | 列名不同，各自说明 |
| 滑点与冲击 | 分开两列 | 合在 `slippage` 里 | 容量分析只关心冲击，所以分开 |
| 比例 | 小数 | 小数 | 相同 |
| 缺失值 | `to_dict()` 里 NaN、inf 记为 `null` | 同 | 相同 |
| 键名 | 英文小写下划线；行名列叫 `date`、`aum`、`year`、`sector`、`factor`、`group`、`symbol` | 列式 | 以后作为可选小节接入 |

### 与主干的接口

行情、账户规则、费用表、信号错位、风险模型输入都直接用主干：`ashare.backtest.market_from_panel` /
`market_inputs` / `boards` / `execution_targets`，`panelbt.markets.ASHARE.costs`，
`ashare.risk.risk_inputs` / `industry_names`。`src/ashare/analysis/adapters.py` 只剩转发：分析函数的
输入是一个面板，不一定带数据句柄，所以 `risk_source(panel)`、`panel_config(panel)` 在面板是 `LazyPanel`
时把它的数据句柄交给主干（取证券表的板块、申万行业名），否则板块按代码前缀推断（推断不出时与主干一样
报错），行业因子以申万代码命名。没有保留自己的费用表、板块规则或行情构建。指数代码到面板权重字段的对应 `INDEX_FIELDS`
抄了一份：数据层的 `catalog` 是内部模块，层边界检查不许包外导入；有测试核对两者一致。

留下的两处与主干语义不同的实现：
- `total_returns`：见上文「时间」，与 `adjusted_returns` 的差别只在停牌日记 0 还是 NaN。
- `reference_close` / `reference_prices`：主干没有导出 panelbt 估值价的数组版（内核在 Rust 里逐格算），
  这里按内核的规则写了一份，并用「持仓市值 + 现金 = 权益」逐日核对。

## 真实数据例子：沪深 300 内低波动 30 只、月度调仓

运行 `python -m ashare.analysis.example`。面板从 2013-01-04 起（风险模型的描述子需要约一年历史），
归因区间 2015-01-05 至 2026-11-12，共 2881 个交易日。

策略：每月最后一个交易日收盘后出信号，用 `execution_targets` 移到下一交易日开盘成交。信号：在当天的
沪深 300 成分里，取此前 60 个交易日日收益标准差最小的 30 只，等权，合计 99%。波动率只用有行情、
未停牌的交易日计算，信号日停牌的股票不选（否则长期停牌、价格不动的股票会被当成「低波动」）。初始资金
1000 万元，按 A 股整手成交，费用用主干的 `ASHARE.costs`。基准是沪深 300 的持仓收益（月末快照，快照
之间按成分股收益漂移）。

这正是低波动组合应有的样子：低贝塔、低换手的大盘价值股。风险模型里残差波动已经对贝塔和市值做过正交，
所以低波动的主要暴露落在贝塔上。

**特质项为什么是很大的负数。** 特质项链接后 −43%，而累计主动收益是 +42%。逐项查过：

1. **链接放大了绝对值，但没有改变符号。** 不链接的逐日算术和：特质 −25.8%，主动收益 +13.9%。
   GRAP 把第 t 天的贡献乘以此前组合的累计增长（这个组合 11.9 年涨了 92%），所以每一项的绝对值都放大
   约 1.7 倍，因子项也一样。Carino 给出的数几乎相同（特质 −41.9%）。放大是复利本身的结果，不是链接方法
   单独针对特质项造成的。
2. **组合侧与基准侧。** 逐日算术和里，组合持仓自身的特质收益是 −21.3%，基准持仓的特质收益是 +4.5%
   （相减后为 −25.8%）。约八成来自组合这边：低波动的股票在风格解释之外，长期每年约跑输 2%。
3. **停牌与未覆盖。** 停牌持仓在特质项里的部分（停牌日收益为 0、因子项照算的差额）逐日合计 +1.0%；
   未覆盖证券为 0。两者都不是特质项为负的原因。
4. **因子项与特质项在相互抵消。** 三类因子的链接合计是 +106%，特质 −43%。逐日看，因子贡献合计与特质
   贡献的相关系数是 −0.24。在这个只选 30 只大盘低波股、并且重仓银行的组合上，截面回归把一部分收益在
   「风格」和「特质」之间分得并不稳定。
5. **换估计池或回归权重后的变化（逐日算术和）：**

   | 回归设定 | 市场 | 行业 | 风格 | 特质 | 因子与特质的日相关 |
   |---|---|---|---|---|---|
   | 默认（全市场估计池，权重 sqrt(市值)） | −0.038 | +0.217 | +0.324 | −0.258 | −0.24 |
   | 只用沪深 300 成分做估计池 | −0.034 | +0.282 | +0.238 | −0.241 | −0.31 |
   | 市值加权（权重 = 市值） | −0.016 | +0.203 | +0.458 | −0.400 | −0.27 |

   市值加权时，回归更贴合大盘股：风格多拿了 13 个百分点，特质相应少了 14 个百分点。只用沪深 300 做
   估计池时，行业和风格之间挪了约 7 个百分点，特质变化不大。「风格 + 特质」的合计是稳的，两者之间的
   分界取决于回归设定，十二年里差 ±15 个百分点，约合每年 1 个多百分点。
6. **独立核对。** 在真实数据 2020 年初的 30 个交易日上，用逐股、逐因子循环的参考实现
   （`test/analysis/analysis_reference.py`）重算同一组输入，各项最大差 2.9e-17。

**使用者该怎么读这个数。** 特质项是「风险模型的风格解释不了的部分」，它与风格项此消彼长。这个低波组合
靠价值、低贝塔等风格赚钱，同时在这些风格之外每年约跑输 2%。结论要看「风格 + 特质」的合计与逐年数字，
不要单独解读一个十几年的链接累计值。

**交易项。** 链接后 −6.0%，逐日算术和 −2.4%。按「当天没有成交」分开（判据：引擎换手为 0，且佣金、税、
过户费、滑点、冲击、融券费、红利税、融资利息全为 0；归因区间内 2718 天）：
- 有成交的 163 天合计 −2.54%：调仓日开盘成交价与收盘价之差，以及挂单重试日的成交。
- 没有成交的 2718 天合计 +0.155%，单日最大 1.5 bp（2015-07-07 −1.47 bp、2015-07-03 +1.39 bp、
  2020-07-10 +1.25 bp，都在分红季）。这部分全部来自派现日的口径差异：这里的个股收益按复权因子算，
  相当于把分红再投资到这只股票（`收盘 ÷ (前收 − 每股派现)`）；panelbt 把分红记成现金
  （`(收盘 + 每股派现) ÷ 前收`）。两者在派现日相差约「当日涨跌 × 股息率」。核对：把个股收益换成
  panelbt 的口径重算，无成交日的交易项合计 −2.5e-15、单日最大 3.4e-16，即恰好为零。这个口径差逐日
  记在诊断 `dividend_convention` 里，没有成交的日子交易项与它直接对上。

### 风险归因

日频跟踪误差平均 0.88%（年化约 14%）。平均占比：风格 73%，行业 16%，特质 9%，市场 1.5%。

偏差统计量（2880 天）为 0.964。z 的峰度 3.98，正态区间 [0.974, 1.026] 偏窄；默认的块自助区间是
[0.948, 1.049]，峰度修正区间 [0.968, 1.032]。0.964 落在自助区间内：在厚尾和波动聚集下，看不出风险

## 验证

- **参考实现**（`test/analysis/analysis_reference.py`）：逐日、逐股、逐因子的纯 Python 循环，不调用本包任何代码。
  - 收益归因的各项对拍，包括风险模型没覆盖的证券、某天没有因子收益两个分支。
  - GRAP 与 Carino 的期末值：参考实现用直接公式，不用递推。
  - Brinson 各行业三项，包括组合或基准缺某个行业、现金一行。
  - 风险：在稠密协方差 `BFBᵀ + D` 下算组合风险与个股贡献，对拍。
  - 单笔成交的五项成本。
  - 个股收益：后复权价整体沿用；停牌中送转、停牌中派现、停牌中复权因子缺失三种情形。
  - 真实数据：抽 2020 年初 30 个交易日，用同一个循环参考实现核对收益归因的逐日每一项，最大差 2.9e-17。
- **恒等式**：收益、风险、Brinson 三处，逐日与累计都测。
- **已知答案**：
  - 只暴露一个风格因子的组合：其余各项都低于 1e-15。
  - 与基准完全相同的组合：各项恰为 0。
  - 只有行业之间配比不同的组合：选择与交互低于 1e-16。
  - 组合留 10% 现金、其余与基准同比例：配置项每天恰为 −10% × 基准收益。
  - 按风险模型真实生成收益时，偏差统计量落在 95% 区间内。
  - 停牌中先送转、再派现：`result_weights` 的持仓市值加现金与 panelbt 的权益逐日相等（1e-12），
    没有成交的日子交易项小于 1e-12；派现扣红利税的那天，税记进成本项、交易项仍为 0。
  - 估值价：同一天派现与送转，先按送转前股数派现再送转（4.75 而不是 4.5）。
  - 只给组合列建风险历史：告警，`uncovered_specific` 非零；给全列时不告警。
  - 停牌持仓的特质诊断等于 `−(h_p − h_b)·B·f`，其余日子为 0。
  - 容量：带最低佣金的合成成本曲线先降后升，上升段交点与下降段交点处的成本都等于门槛、最低点低于门槛；
    去掉最低佣金后下降段交点消失、上升段交点不变；毛超额为负、门槛低于最低成本、门槛高到搜索上限、
    `breach_share = 0`、搜索下限处已越过这五种边界都给出对应状态和 NaN/inf，不返回搜索边界；最低佣金把
    账户打穿的规模不会被当成「成本最低」。
  - 偏差区间：厚尾（t 分布，自由度 4）时自助区间和峰度修正区间都比正态区间宽 1.5 倍以上；正态数据上
    三者宽度相差不到 20%。
  - 输入错误：风险模型为 None 或类型不对、基准数组形状不对、`cost_breakdown` 收到权重而不是 Result，
    都报出说明怎么改的 TypeError / ValueError。
- **Brinson 教科书例子**：三国例子，取自 Carl Bacon《Practical Portfolio Performance Measurement and Attribution》。
  组合权重 40/30/30%、基准 40/20/40%；组合收益 20/−5/6%、基准收益 10/−4/8%；组合 8.3%、基准 6.4%。
  Brinson-Fachler 配置 0/−1.04/−0.16%，选择 4/−0.2/−0.8%，交互 0/−0.1/0.2%，合计 1.9%。
  数值自行手算核对，出处编号未核实。
- **因子收益**：与风险模型内部的回归逐位相同；与独立的 numpy 加权最小二乘（`ashare.risk.kernels.cross_section`，
  权重用前一日市值）相差在 1e-9 以内；改动 t+1 日以后的价格，≤ t 日的因子收益不变。合成数据的市值逐日变化，
  所以「用当日市值加权」这种前视能被测出来。
- **容量对账**：合成数据含停牌挂单、停牌中送转和派现、同一天派现加送转、退市、买单按现金缩放，费用用主干
  费用表另加按股收取的佣金和过户费。在这上面，解析模拟与 panelbt（不取整、无上限）逐笔相等：各项成本相对
  误差在 1e-9 以内，期末权益在 1e-10 以内。真实数据上的对账见上表。
- **真实数据上的容量交点** 不写成测试：仓库的测试框架禁止测试读真实数据根目录（`ashare.data.store` 的守卫）。
  上面的成本曲线和交点由 `python -m ashare.analysis.example` 重跑得到。
- **容量求解的批量化**：一批规模一起模拟与逐个单独模拟相比只差浮点舍入（1e-12）；多分法的交点往可行一侧
  挪 rtol 就落回门槛以内；粗网格找到的最低成本不比细网格高 2% 以上；用户给的规模被最低佣金打穿时，
  表里成本率与扣成本后超额为 NaN、`wiped_out` 为 1；现金只是小额透支、权益始终为正的规模不算打穿。
- **分红口径差**：正常交易日派现、当天价格照常涨跌时，没有成交的日子交易项与诊断 `dividend_convention`
  相差不到 1e-15。
- **结果转 dict**：所有结果对象的 `to_dict()` 都能用 `json.dumps(..., allow_nan=False)` 序列化；
  `Attribution.to_dict()` 默认不带诊断，`to_dict(diagnostics=True)` 带。其余结果对象没有诊断字段。

### 变异检查

全市场的暴露约 7 GB，放不进内存。测这一项时用一个按块返回同一块暴露的对象代替：计算量和访存方式

  向量化代码。

### 容量求解

真实例子（低波组合，全市场 5923 列，2013-01-04 起），`capacity(..., aum=7 个规模)`，三次取中位数，
本机负载（1、5、15 分钟）约 12–16。

| 做法 | 解析模拟 | 中位数 | 三次 |
|---|---|---|---|
| 逐个规模模拟，网格逐点、二分 30 步 | 144 次单规模 | 15.7 s | 15.7 / 14.7 / 18.5 |
| `simulate_many` 成批：表与网格一批，三个交点的多分法 5 批，毛收益 1 次 | 7 批 | 3.1 s | 3.4 / 3.1 / 3.0 |

同一做法在不同负载下又测了三组，中位数 2.3–4.1 s。

成本容量 7.1461603 千万对 7.1461603 千万（相对差 2e-8），最小可行规模、成交量容量的相对差都在 2e-7

## 已知局限

- 暴露只保存组合与基准出现过的证券（`columns`），不把全市场十五年的暴露整体放进内存；截面回归仍用当天的全部证券。
- 解析容量不做整手、不设成交量上限。真实规则下的差别，看 `rerun=True` 的并排表。
- 个股收益按复权因子算（分红再投资口径），panelbt 把分红记成现金。差异只出现在派现日，落在交易项里；真实
  例子 11.9 年合计 +0.155%，单日最大 1.5 bp。换成 panelbt 口径可以让它恰好为零，但持仓收益就和风险模型
  回归用的收益不是同一口径了，所以没有换。
- 停牌持仓：收益为 0，因子项照算，差额在特质项里（诊断 `suspended_specific`，真实例子合计 +1.0%）。
- 风格与特质的分界取决于风险模型的回归设定，见上面的调查。分析结论应该看「风格 + 特质」的合计和逐年数字。
- 基准用持仓收益（月末快照加漂移），不是指数点位。快照之间的成分调整和指数自身的计算细节，会让它与指数
  涨跌有小的差别。
- 偏差统计量只报告，不校正：低波组合 0.964（在自助区间内）、动量组合 1.101（高于区间），方向随组合而变。
