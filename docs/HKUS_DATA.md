# 港股、美股数据

港股（港交所主板 + 创业板）和美股（纽交所、纳斯达克、美交所）的原始库、「交易日 × 证券」面板、读取入口和独立校验。设计见 `docs/DESIGN.md` 6.1.3。交易规则（费用、每手、税）见 `docs/markets/hk_rules.md`、`docs/markets/us_rules.md`；回测档案由 `panelbt` 那条线做，本文只管数据。

> **先看这五条**
>
> 1. **两地面板都是事后清洗过的数据，不是严格的时点数据。** 一次公司行为执不执行、要看下一个成交日的前收或价格（停牌中的事件要等复牌）；美股一列在哪里拆成两段、旧列按什么价清算，要看复牌那天的价格；美股 `delist` 要知道「以后再没有成交」。以 end=D 构建与全量构建比，D 及以前不同的格只出现在这些字段、而且只在「这一列在 D 及以前最后一次成交之后」的那段（第四节末「哪些字段依赖以后的数据」，测试守住）。另有日内前视：只靠当天收盘价才印证的事件，开盘时还不知道（`action_check = 3`）。
> 2. **美股面板是试验性的，目前是「价格收益加拆并股」，不是全收益。** 源的美股因子只对一部分证券含现金分红（AAPL、MSFT、XOM、WMT 的纳斯达克序列都不含），面板统一不计现金分红。复核人估的量级：大票股息率 1–4%，市值加权组合每年约低估 0.5–1.5 个百分点，**高股息策略每年约低估 3–4 个百分点**，按股息率、价值分组的检验会有系统偏差。正式回测还缺分红来源和退市原因（见第七节）。
> 3. **源因子与前收、价格都对不上的公司行为不执行**（`action_suspect` 为真）。`action_suspect` 与证券表的 `action_suspect_dates` 本身由以后的数据决定，**只用于事后诊断，不能用来选样本或剔除时段**（那样做就是前视）。
> 4. **`universe="sample"`（2010 年起的 200 只样本）按 2026 年市值分层抽取，绝大多数证券活到了今天，有幸存者偏差，不能用来得出回测结论**，只用于开发和抽查长历史上的公司行为。`universe="all"` 是按交易日分区里出现过的全部证券（开发库为近 3 年，含期间退市的），可以做截面研究。
> 5. **美股：没有三大交易所因子的那天不可交易。** 证券转到场外后源的三大交易所因子就停了，日线照样有、常有错价（AONC 三天里 12.0 → 0.1 → 10.0）。当天有成交却没有因子的格 `tradable` 为假（行情留在 `has_quote`、`close` 里，只作参考），连续 5 个这样的成交日在第 5 个那天退市，按偏悲观的清算价了结（第三节）。上市期内两天都有因子、价格却跳出 [1/3, 3] 的情形仍然存在（近 3 年 839 处，统计上以小盘股和生物科技股的真实暴涨暴跌为主，不能排除夹杂少量源漏记的拆并股），校验单列计数、按规则登记（第五节、第六节第 19 条）。

本文的数字都来自 2026-11-13 在开发数据根 `data/dev/hkus/` 上的下载：两地「全部证券近 3 年」（港股 2023-11-13 至 2026-11-12，美股至 2026-11-11）加「2010 年起的 200 只样本」。

## 最短例子

```bash
R=/path/to/root
python -m ashare.data --root $R --market hk sync-overseas --start 2023-11-13 --end 2026-11-12 --datasets hk_calendar hk_securities
python -m ashare.data --root $R --market hk select-sample-overseas --asof 2026-11-12   # 抽 2010 年起的样本，写 sample.json
python -m ashare.data --root $R --market hk sync-overseas --start 2023-11-13 --end 2026-11-12
python -m ashare.data --root $R --market hk build-overseas                   # 近 3 年全部证券
python -m ashare.data --root $R --market hk build-overseas --universe sample # 2010 年起的样本
python -m ashare.data --root $R --market hk verify-overseas                  # 报告在 <root>/hk/reports/overseas_verify.md，不通过时退出码非零
```

美股把 `hk` 换成 `us`。

```python
import ashare.data as ad

hk = ad.open("/path/to/root", market="hk")                   # 默认 universe="all"
p = hk.panel(["close", "adj_factor", "connect_eligible"], start="2025-01-02")
p.dates, p.symbols, p["close"]                                # T×N 只读数组（港元）
hk.securities().collect()                                     # 证券表（含当前每手 board_lot_current）
hk.fx("CNYHKD").collect()                                     # 人民币中间价，带可用时刻 available_at

us = ad.open("/path/to/root", market="us", universe="sample") # 2010 年起的样本（只用于开发抽查）
us.panel(["close", "split"], symbols=["AAPL"])["split"]
```

数据根：港股写在 `<root>/hk/`、美股写在 `<root>/us/`，各有一份清单，与 A 股的 `<root>/cn/` 互不相干。A 股、期货的子命令（`sync`、`build-panel`、`verify`、`gc`、`sync-futures` 等）带 `--market hk|us` 时直接拒绝（以前会把 A 股数据写进 `<root>/hk`），`ashare.data.reader.Data` 也只读 A 股。A 股的同步计划、`required`、`status`、`verify` 报告、内容版本、面板版本在同一个根下加入港美股（含未完成、失败的分区）前后逐位相同（`test/data/test_hk_isolation.py`）。

## 一、数据权限实测（2026-11-13）

每个接口先用一次最小的只读请求试，再对主要接口各做一次 25 次、两个接口各 150 次的顺序突发（不并发）。没有遇到限流（code 40203）：150 次请求在 12–18 秒内全部成功，即至少每分钟 500 次不限；更高的上限没有去试。正式同步按每接口每分钟 200 次、每个数据集 2 个并发，全程没有触发退避。返工这一轮没有向 Tushare 补取数据（只两次各 2 个请求查美股 2026-11-12 是否已发布，都还没有）。

## 二、数据集与时点

原始数据集登记在 `catalog.OVERSEAS_DATASETS`（不并入 A 股的 `DATASETS`），原始字段保留 Tushare 原名，每个分区一个不可变 Parquet 修订：

| 数据集 | 接口 | 分区 | 时点 |
|---|---|---|---|
| `hk_calendar` / `us_calendar` | `hk_tradecal` / `us_tradecal` | 一个分区（1980 至明年年底） | 交易所提前公布；风球、临时休市只在事后体现 |
| `hk_securities` | `hk_basic` | 按状态 L/D/P | 当前主表；名称、每手是现值 |
| `us_securities` | `us_basic` | 一个分区 | 当前主表 |
| `hk_daily` / `us_daily` | 日线 | 按交易日 | 收盘后（港股约 18 点、美股次日早上） |
| `hk_adjfactor` / `us_adjfactor` | 复权因子 | 按交易日 | **前复权快照**：每次除权都改写整段历史，只在同一次同步里可比 |
| `hk_daily_hist`、`hk_adjfactor_hist`、`us_daily_hist`、`us_adjfactor_hist` | 同上 | 按证券（样本，2010 年起） | 同上；每只证券一次取完 |
| `hk_connect_sh`、`hk_connect_sz` | `stock_hsgt` | 按交易日 | 当天名单，2025-08-12 起 |
| `hk_connect_hold` | `hk_hold` | 按交易日 | 日终持股，次一交易日公布 |
| `overseas_fx_daily` | `fx_daily` | 按货币对 | 见「汇率」 |
| `overseas_fx_midrate` | `fx_midrate` | 按货币对 | 北京时间 9:15 公布 |

**前复权快照的处理**：两地因子都以最新交易日为 1，某天除权后此前整段历史被一起缩放，两次同步取的两天不能相除。所以因子数据集每次同步都在请求范围内整段重抓，每个分区记同一个 `snapshot`；面板构建要求区间内快照唯一，否则报错（`test_snapshot_mismatch_rejected_then_full_refresh_fixes` 模拟「只补新日子」时第 20 天的派息让旧段整体缩放，构建被拒）。代价是每次增量都要重抓全部因子分区（见第六节的估算和建议）。

## 三、面板字段

两套代次：`all`（按交易日的全部证券，开发库为近 3 年）和 `sample`（2010 年起的样本，见文首第 3 条）。存储写法同 A 股面板（`<root>/<市场>/panel_<universe>/<版本>/<字段>.npy`，`current.json`）。同名字段与 A 股面板含义和单位相同：价格是每股交易币种元，成交量是股，成交额是交易币种元。A 股专有的涨跌停、ST、行业、指数权重、估值字段不提供。

版本键包括：区间内全部输入分区的内容哈希、区间、范围、样本名单的整份内容（`all` 的证券表有 `in_sample` 列）、影响输出的四个模块（`overseas_actions.py`、`overseas_fields.py`、`overseas_panel.py`、`overseas_sync.py`）的源码和几个模块常量。改了其中任何一样都会换代。

**美股的范围**：只放在纽交所、纳斯达克、美交所有过因子的代码（按因子表的 `exchange` 判断，含已退市的，不用证券表当前的类别，避免幸存者偏差），再去掉证券表只标为优先股的、以及没有类别且不是 1–5 位纯字母或第 5 位是 W、U、R（纳斯达克的权证、单位、权利）的代码；行情从这只证券第一次有三大交易所因子的那天起取，一直取到日线自身的范围为止（不按因子序列的结束日截断，那要用到以后的数据）。**当天有成交却没有三大交易所因子的格不可交易**（`tradable` 为假，行情照旧留在 `has_quote`、`close` 里）：这当天就能判断，多为转到场外后的行情，常有错价；在因子覆盖期内这种情形很少、而且很短。还在上市时**连续 5 个这样的成交日，在第 5 个那天退市**：从那天起不算上市，直到再有带因子的成交；清算价 = min(最后一个可交易日收盘, 当天收盘 × 其间执行了的倍数)，记在 `delist_recovery`，与拆段同一口径。取 5 的依据：开发库近 3 年里，因子缺失后又恢复的成交段长度是 1 天 36 次、4 天 2 次，再往上是 22 天起的长段（转场外后又回来）；5 能把偶发缺失和转场外分开，最多晚 4 个成交日退市（这几天本来就不可交易）。场外、NYSE Arca、Cboe 的原始分区照旧保留，不进面板。近 3 年：日线里 27746 个代码，18550 个没有三大交易所因子（场外、ETF 等），3042 个按类别去掉，留下 7036 只，拆段后 7056 列；有成交却没有因子的格 51021 个，无因子退市 332 次（其中 154 次清算打了折），因子停止后仍有行情的列 555 列。

**美股拆段**：两次成交之间价格跳出 [1/3, 3]（按引擎记账，扣除执行了的公司行为），且缺口长于 60 个交易日（代码复用、长停牌后复牌）或缺口里有不执行的可疑事件（源漏记了合股、分位以下价格的合股等）时，从复牌那天起另起一列 `代码#2`（再有就 `#3`），引擎不会把这次跳变当成收益。证券表的 `segment` 记段号。**旧列从新列开始那天（复牌日 b）起不再上市，并在 b 退市**，新旧两列不会同时可交易；清算按对多头偏悲观的假设：清算价 = min(停牌前最后成交日收盘, 复牌收盘 × 缺口里执行了的倍数)，真实暴跌照实承受、暴涨不给，记在 `delist_recovery`（下表）。近 3 年拆了 20 处（第三轮把因子停止后的场外行情改为不可交易后，转场外尾段造成的拆段没有了），其中 7 处缺口长于 60 天；16 处旧列在复牌日退市清算（4 处打了折），另 4 处（AZUL、SBDS、SCPX、WORX）旧列在复牌前已按无因子规则退市，复牌日不再另记。复核人点名的三例：SHAZ（2024-10-30 复牌）回收率 0.097、ELOX（2026-03-18）0.133，与持有者在复牌日的真实价值倍数相同（原来按停牌前价格清算，等于躲过了这段暴跌）；AZUL 现在在因子停止后的第 5 个无因子成交日（2025-06）就退市，不再拖到 2026-06-01 复牌；跳涨的（如 SNYR ×45）回收率为 1，涨幅不给。

| 字段 | 单位 | 两地 | 口径 |
|---|---|---|---|
| `open` `high` `low` `close` | 交易币种元/股 | 都有 | 不复权。港股 2020-07-02 至 2023-12-29 的收盘价改用因子表的精确值（`close_price`，相差不超过半分时），开高低价仍是四舍五入后的值；美股非正价格（无成交日源写 0）记为缺失 |
| `previous_close` | 同上 | 都有 | **两地不同**：港股是除权除息后的参考价，美股是上一日原始收盘价 |
| `volume` | 股 | 都有 | 港股是交易所全日成交量；美股与公开的综合成交量一致（AAPL 2024-01-02 为 82488674 股），是否含盘前盘后源没写 |
| `amount` | 交易币种元 | 都有 | 港股币种看证券（人民币柜台为人民币）；美股美元，2016 年前多为空 |
| `vwap` | 交易币种元/股 | 都有 | 美股取源的 `vwap`，港股为 `amount / volume` |
| `adj_factor` | 倍 | 都有 | 只累乘**执行了的**公司行为（拆并股、按股数的调整、港股等效现金再投资），每列第一个有因子的交易日为 1，只有比值有意义。美股不含现金分红；可疑事件不计入 |
| `action_ratio` | 倍 | 都有 | 源因子比 r = F[t]/F[t−1]（同一条序列内部；换序列的拼接处记 1），无事件为 1，无因子为 NaN |
| `split` | 倍 | 都有 | 执行的股数调整（每股变成几股）：`action_source` 为 1、3、4 时不为 1 |
| `equivalent_cash` | 交易币种元/股 | 都有 | 只在 `action_source=2`（港股小比值）时不为 0 |
| `action_source` | 枚举 | 都有 | 0 无事件；1 拆并股；2 等效现金（港股，r<1.10）；3 因子下调非整数比（按股数）；4 分不出、大比值（r≥1.10，按股数，不扣税）；5 美股不执行（现金类调整，或合计比值不到 1.25 倍的窗口里价格没印证的非整数股数调整）；6 前收、价格都没有印证（不执行）；7 最后一次成交之后的因子变化（并购、退市，不执行）。规则见第四节 |
| `action_suspect` | 布尔 | 都有 | `action_source` 为 6、7 的格：源因子变了但没有执行。由以后的数据决定，只用于事后诊断 |
| `action_check` | 枚举 | 都有 | 事件格所在窗口的印证方式：0 无事件；1 交易所前收（港股）；2 开盘价；3 只靠当日收盘价（日内前视）；4 没有上一个成交日的小比值窗口；5 没有印证（即 6）；6 最后成交日之后（即 7） |
| `has_quote` | 布尔 | 都有 | 源当天有日线且收盘价为正（港股停牌日、无成交日都不出行；美股无成交日的陈旧行收盘价照旧、成交量为 0，`has_quote` 为真、`tradable` 为假） |

## 四、公司行为：由因子比推出，用交易所前收或价格印证

两地都没有分红送转、拆并股的事件明细接口，只有前复权累计因子。规则（`ashare.data.overseas_actions`）：

1. **噪声**：|r − 1| ≤ 1e-5 不算事件（源因子只留 6 位小数）。
2. **窗口**：一个事件落在「上一次成交 a 之后、下一次成交 b 及之前」，同一窗口的事件合起来印证（停牌期内先合股后派息算一个窗口）。窗口合计比值 R。
3. **港股先看交易所前收**：b 的前收 × R 与 a 的收盘相对差 ≤ 0.5%（大比值窗口 1%：前收与因子隐含的比例对得上就是真实除权，开发库上只多执行 08121.HK 2024-08-20 一件；再放宽前收半个价位折回去的取整误差；源日线四舍五入期内价位按 0.01）就算印证（`action_check = 1`），不再看价格：合股、大比例供股时停牌前后价格常被同时打压，价格印证不了，前收却已按除权调整（复核的 08195.HK 2017-10-09 20 合 1：价格算出持有者 ×7.7，真实是 −61.5%）。前收缺失或对不上时退回价格印证：缺口窗口（a、b 不相邻）里交易所的前收是 b 前一天的按盘价，没有成交也会变，不是 a 的收盘；少数相邻窗口源的前收没有除权。
4. **价格印证**（美股；港股前收不能印证时）：a 的收盘 p0，b 的开盘或收盘 p1（开盘先试，任一个通过就算：小盘股的开盘价常沿用旧价），持有者价值倍数 h = R·p1/p0。max(R, 1/R) ≥ 1.25 时要求 |ln h| ≤ min(½|ln R|, cap)——价格跳变要比「什么都没发生」更接近因子说的比例，cap 在 b − a ≤ 5 个交易日时为 ln 2，更长为 ln 3。更小的窗口价格分不出事件与日常波动，只要求 |ln h| ≤ ln 1.5（不明显矛盾）。只靠 b 的收盘价才通过的记 `action_check = 3`。
5. **美股小窗口里的非整数股数调整**：max(R, 1/R) < 1.25 的窗口里本该按股数执行（3、4）的非整数比，多是特别股息或源把现金分红记成了下调，b 的开盘价要走到隐含调整的一半以上（|ln h| ≤ ½|ln R|）才执行（只认开盘：引擎在开盘执行，也不用当天收盘才知道的信息），否则与 5 一样不执行。整数比拆并股照常（第 4 条）。
6. **不执行**：印证不了的（6）、最后一次成交之后的因子变化（7：并购、退市日因子跳到 1）一律 `split=1`、`equivalent_cash=0`、`action_suspect` 为真。原则是宁可不执行并标记，也不执行错的。
7. **执行的归类**：max(r, 1/r) ≥ 1.05 且是整数比 → 拆并股（1，`split=p/q`）。整数比的认定：比值 < 3 时分母 ≤ 10、相对差 ≤ 2e-4；3–10 倍分母 ≤ 2；10 倍以上只认整数 n:1 / 1:n、绝对差 ≤ 2e-3；合股另放宽到因子比的绝对差 6e-5（港股源只留 4 位小数，1/12 写成 0.0833）；比值上限 1000。收紧只影响标签：印证过的非整数大比值照样按股数执行（4）。其余 r > 1：r < 1.10 港股按等效现金（2）、美股不执行（5）；r ≥ 1.10 按股数（4，`split=r`，无现金）。r < 1 的非整数比按股数（3）。
8. **等效现金**：除权前参考价 × (1 − 1/r)；参考价是 a 的收盘，同一窗口里前面每个事件之后再除以它的 r（合股后派息用合股后的价位）。复核发现的两例：01129.HK 2024-12-11 10 合 1、12-12 r = 1.2107，01389.HK 2024-01-31 10 合 1、02-01 r = 1.1624：两次都是大比值，现在按股数执行；小比值的写法见 `test_hand_cash_after_consolidation_in_gap`（手算：收盘 0.05，10 合 1 后参考价 0.5，再 r = 1.05，等效现金 0.5 × (1 − 1/1.05) = 0.02381）。

**整数比规则的误判率**（`test_random_ratio_false_split_rate`，均匀随机的 r 各 2 万个，只看比值不看价格）：[1.05, 3) 里 2.6%、[3, 10) 里 0.5%、[10, 100) 里 0.4% 被认成整数比（原规则 [10, 100) 是 57.9%）。加上价格印证后，价格不动的随机大比值（≥ 1.25）**一个都不会执行**；1.05–1.25 之间价格分不出：整数比和港股（前收印证）照常，美股非整数的股数调整要价格走到一半以上。

**美股的序列选择**：只用三大交易所的序列；某天有几条时取开始日最早的那条（先有的序列，开始日不晚于当天，当天可知），一样早按纽交所、纳斯达克、美交所；不看序列哪天结束、有多少天（那要用到以后的数据）。转板时旧交易所的序列先有、先用，它结束后换到新交易所的序列；因子比只在同一条序列内部算，而且该序列的上一行必须正好是这只证券上一个取用的日子，否则记 1（拼接），不会把另一条序列已经算过的事件再算一遍。转板的 24 个代码（复核人数出的 ABCB、KHC 等）现在两段都有因子；近 3 年有 96 个代码用到两条以上序列、22 处拼接。

**对回测的影响与给港股档案的衔接建议**：

- `action_source = 1、3、4`：按 `split` 调整股数，没有现金，不扣税。
- `action_source = 2`（港股 r < 1.10，绝大多数是派息）：按等效现金记账、扣投资者适用的股息税（港股通 20%，港股非 H 股 0%、H 股 10%）。混在里面的小供股会被多扣税，误差不超过 20% × (1 − 1/r) ≤ 1.8%。
- `action_source = 4`（r ≥ 1.10，供股、公开发售、分拆、送股、特别派息）：按股数调整、不扣税。偏向：大额特别派息被当成无税再投资，少扣税；原方案（按现金扣 20%）在 00897.HK 2024-03-11 r = 5.86 这样的供股上凭空亏约 17%，现在没有了。阈值 1.10 的依据：近 3 年港股分不出的事件里 r < 1.10 的 4366 次、≥ 1.10 的 332 次，单次派息超过股价 10% 的很少，而供股、分拆几乎都在 1.10 以上。
- `action_source = 5、6、7`：不执行。6、7 不能用来排除股票池（见文首第 3 条）；要做稳健性检查，就把结论在「去掉这些证券」前后各跑一遍、两个都报。
- 公司行为的裁决用的是当天收盘后的因子与价格，只能按事件在除权日开盘调整持仓，不能当盘前信号用。严格的使用者可以把 `action_check = 3` 的事件当作当天收盘后才知道：对收盘撮合影响有限，对开盘撮合有影响。
- **将来 `ashare` 按地区建 `bt.Market` 时的退市处理**：`delist` 直接传；没有 `delist_recovery` 的格按档案的退市假设（`HK_DIRECT`、`US` 的 `delisting="zero"|"last"`）。拆段旧列和无因子退市的偏悲观清算，`panelbt` 现在只有标量的 `delist_recovery`，**推荐给 `Market` 加逐格回收率**（NaN 用档案的标量假设，有值就用这一格；引擎只在退市那一格多读一个数，Rust 内核和参考实现各加一处，「全为同一值」时与标量写法逐位一致；留作后续，这一轮不动引擎）。不改引擎的办法是把 `delist` 挪到下一行、把引擎用的 `close` 在退市行写成「记账价 × 回收率」，但它会让直接读 `close` 的因子（动量、收益率）在那一行看到一次假暴跌，退市行是最后一行时没有下一行可挪，了结晚一天也让当天的估值和现金与其他退市不一致；真要用，只能在构造引擎输入时临时改写，绝不落盘。另外，无因子退市前那几个不可交易的日子，引擎的记账价会跟着场外收盘价走（回收率是相对那个记账价算的，清算金额不受影响，但这几天的估值会有波动）；构造引擎输入时如果把这些格的收盘价置空，回收率就要按「最后一个可交易日收盘」重算，不能直接用面板里的值。

**哪些字段依赖以后的数据（截断不变性）**：以 end=D 构建与全量构建相比，D 及以前的格逐位相同，例外只有 `overseas_panel.LOOKAHEAD_FIELDS` 里的字段，而且只在「这一列在 D 及以前最后一次成交之后」的格（停牌或退市后、下一个成交日还没到的那段）：

| 字段 | 为什么依赖 D 之后 |
|---|---|
| `action_source`、`action_suspect`、`action_check`、`split`、`equivalent_cash`、`adj_factor` | 事件之后的下一个成交日在 D 之后：截到 D 时只能记 7；全量构建看那天的前收或价格才定执行还是 6，`adj_factor` 从这个事件起的累乘随之变化 |
| `delist` | 美股退市要知道以后再没有成交：截到 D 时最后一次成交满 20 个交易日就记退市，全量构建里之后又有成交则不记 |

拆段（`代码#2`）和 `delist_recovery` 只用到复牌日 b 及以前的数据，不在清单里：截到 D 时，b 在 D 之后的列还是一整列，D 及以前的格与全量构建的旧列相同。证券表的 `exchange`、`factor_includes_cash`、`last_quote`、`action_suspect_dates` 是整个区间的汇总，也用到以后的数据。测试 `test/data/test_hk_us_truncation.py` 在两地合成数据上逐日截断核对；无因子退市只用当天及以前是否有因子，也不在清单里（清单这一轮没有变）。真实开发库上用原始库副本截断构建、与全量比对（第二轮的代码；美股 D = 2025-06-10、2026-03-05，港股 D = 2024-08-19），不同的格全部落在清单字段的那段里：美股前者 5 格 `delist`，后者 AZUL 停牌中的 3 个事件（`action_source`、`action_check`）和 1 格 `delist`；港股 2 列停牌中的事件。第三轮新增的无因子规则只用当天及以前的信息，由合成数据的逐日截断测试守住，真实库上没有重做截断比对。

## 五、校验（`verify-overseas`）

与同步、面板构建不共用代码，按清单直接读原始 Parquet。每项判 `pass` / `explained` / `fail` / `info`；「已解释」只认已知例外清单 `src/ashare/data/overseas_known_exceptions.json`（逐条写市场、检查项、匹配键和原因编号；按规则登记的条目覆盖一类不符；不放任何由行情算出的数值，测试按白名单核对键集合）。清单外的不符一律 `fail`，命令行退出码非零；清单里有、本次没用到的条目列为过期；「原因未查明」单列计数。面板部分不允许例外；坏数据让面板核对出错时记为失败并照常出报告，不再崩溃。美股原始库检查只看面板范围内的代码和三大交易所的因子。

原始库：清单对文件；日历自洽；日分区覆盖；主键唯一（分「同值重复」「取值冲突」）；日线取值范围；因子表收盘价与日线一致；因子快照唯一；**港股前收**：每一对相邻交易日都核（没有事件的日子即前收 = 上一日收盘），容差 0.5% 或一个价位；美股前收不除权，「因子比与价格跳变矛盾」列为信息（面板必须不执行它们，由面板检查核）；港股上市期与行情；休市日有行；样本历史与按日分区在重叠日上逐值相同。

面板（按字段定义独立核对，不调用构建代码）：抽 2000 格核收盘价、成交量、`has_quote`（拆段的按日期找到所在列）；`tradable` 全量（美股要求当天有成交、而且这只证券当天有三大交易所因子）；公司行为字段之间的约束（`split` 只在 1、3、4 不为 1，`equivalent_cash` 只在 2 不为 0 且为正，3、4 的 `split` 等于因子比，1 与因子比相差不超过 1%，2 的因子比在 (1, 1.10)，5 是现金类或所在窗口合计比值不到 1.25 倍，4 的 ≥ 1.10，因子比变了必须有事件，`action_suspect` 与 6、7 一致，`action_check` 与 `action_source` 对应、美股没有前收印证）；`adj_factor` 相邻两日之比等于执行了的事件；**持有者价值不变式**：执行了事件的窗口按引擎记账（股数 ×split、现金按当时股数计），开盘或收盘的价值倍数至少一个在 [1/3, 3]，最后一次成交之后不许有执行的事件；美股可疑事件处价格跳出 [1/3, 3] 的必须已拆列；港股等效现金按窗口两端口径重算（参考价从上一成交日收盘起、逐个事件除以因子比，停牌缺口之后的也核；没有上一成交日的窗口用复牌日收盘 × 窗口合计比值作参考价）；**港股前收**：容差与构建一致（小比值 0.5%、大比值 1%，再放宽半个价位 × 比值），对得上的窗口必须执行且记前收印证，记前收印证的前收必须对得上，记成价格印证或不执行的都算错；**美股相邻可交易日价格跳变**：两个相邻可交易成交日之间收盘价跳出 [1/3, 3]、中间又没有执行了的事件解释的，逐条列出（`price_jumps`，分「相邻」「缺口」），引擎会把它当成收益；**因子账目**：每个事件的因子比必须是源某条序列当天的比值，港股源因子的每一次变化都必须在面板里有事件；`is_listed`、`delist` 按上市规则重算全量比对（港股按证券表、美股按成交；拆段的旧列在新列开始那天起不上市、那天退市，同一代码两列不许同时上市；连续 5 个没有因子的成交日那天退市），`delist_recovery` 按清算价独立重算；抽查的 2000 格另核 `previous_close`；港股通四个字段按名单分区、上一交易日持股重算全量比对；`price_rounded` 按定义重算。

## 六、已知问题与专门查过的坑

1. **港股日线四舍五入**：`hk_daily`（`hk_daily_adj` 也一样）在 2020-07-02 至 2023-12-29 把全部价格四舍五入到 0.01，此前此后都保留 0.001。面板收盘价改用因子表的 `close_price`（近 3 年 17144 格、样本 26769 格），开高低价和前收没有精确来源，由 `price_rounded` 标记。误差量级（复核人量的样本面板）：期内有行情的格 34% 收盘价低于 0.5 港元，这些格开高低和前收的误差上界中位 3.5%、90 分位 12.5%（0.005 / 价格）。**开盘成交的回测、用前收算涨跌幅时排除 `price_rounded` 格。**
2. **港股代码复用**：证券表用 `代码!.HK` 记已退市的旧公司，日线却把新旧公司都写成 `代码.HK`。面板把新公司上市日前、旧公司退市日前的行改记到 `代码!.HK`（近 3 年 630 行、样本 15853 行）。
3. **港股停牌日、无成交日没有日线**（因子表照常有行）：`has_quote` 分不出停牌与无成交。源没有停牌表。
4. **港股每手**：`hk_basic.trade_unit` 只有当前值（11 只为空），没有历史；合股、拆股常伴随每手变更，用当前值回测历史会算错可买手数。
5. **港股人民币柜台**：`8xxxx.HK`（名称以 R 结尾）是人民币柜台，价格和成交额是人民币，源 `curr_type` 也写 HKD；证券表共 25 只，`currency` 改为 CNY（源值在 `currency_source`），面板价格不换算。**它们与港币柜台是同一家公司的两列**：`primary_symbol` 指向港币柜台（0 + 后四位，名称去掉末尾 R 和随之空出的连字符后相同才认：腾讯控股-R ↔ 腾讯控股、美团-WR ↔ 美团-W），其余证券指向自己；**截面研究按 `primary_symbol` 去重，不要重复计**。
6. **港股通名单**只从 2025-08-12 起有；此前只能看南向持股（2017-03-17 起），「持有」不等于「合资格」。2025-08-12 前的港股通回测没有可靠的标的池。南向持股次日才公布，`connect_held` 已错位一天。
7. **美股代码复用与改名**：证券表 106 行重复代码，日线同一代码同一天有两行，因子表同一代码常有几条交易所序列。源没有永久证券编号；长缺口两侧价格不连续的已拆列（第三节），缺口两侧价格连续的复用（同价位的另一家公司）分不出来。
8. **ADR 与普通股混在一张表**：`us_basic.classify` 分 EQ/ADR/GDR/PF，证券表有 `kind` 列。
9. **美股日线是否含盘前盘后**：源文档没写；AAPL 2024-01-02 的成交量 82488674 股、收盘价 185.64 与公开的常规时段综合数据一致（与记忆核对，未联网复核）。
10. **美股没有上市退市日、没有退市原因**：`is_listed`、`delist` 按成交推断，只在当时可知时生效（第三节）。并购（现金收购价）、破产、转场外分不出；退市后的场外交易和退市收益没有。
11. **美股因子覆盖**：2006 年起才有；2026-08-31 起不再给 ARC、BTS 和场外（面板不受影响）；口径不一致见第四节。
12. **两地日线的成交额币种**：港股是交易币种；美股美元。
13. **汇率时点**：`fx_daily` 的日期是格林尼治日期。实测 USDCNH 有 629 根周日 K 线、198 根周六 K 线，周五只有 585 根，推断多数年份以纽约 17:00 切分、按开盘时的格林尼治日期标注（未核实）：标为 t 的那根在香港时间 t+1 早上 5 点左右才收，对同日港股收盘有约 13 小时前视。**换算用人民币中间价**（北京时间 9:15 公布，早于港股开盘，当天可用）；FXCM 只能错位一天用。`fx()` 的 `available_at` 给出可用时刻。
14. **美股 2026-11-12 的分区**：见第五节。
15. **按区间（`--start/--end`）构建**时，区间首日的因子比恒为 1，首日正好是除权日时该次事件在这个区间面板里没有；港美股面板没有增量构建，每次整段重建（近 3 年港股约 3 秒、美股约 12 秒）。
16. **构建要求日线日期都在交易日历的开市日上**：日历把开市日标成休市时直接报错，不会静默丢掉整天的行情；因子表在休市日的行（美股两天）丢弃并计数。
17. **分拆、清算分配被记成股数变化**：因子比分不出分拆（GE 2024-04-02、MMM 2024-04-01，记 4，按股数调整）与清算分配（ELME 2026-10-23 r = 59，被认成 59 拆 1）。价值上中性，但标签是「股数」：按股数统计换手、按拆股事件做研究时会误读。没有事件明细之前识别不了。
18. **港股 6 类只剩一个窗口**：02330.HK 2024-06-13，前收差 7.8%、价格也对不上（第四节）；不执行，引擎会把复牌后的价格变化当成收益。08121.HK 2024-08-20 大比值窗口前收差 0.87%，容差放到 1% 后执行。
19. **美股相邻可交易日的价格跳变**：两天都有三大交易所因子、价格却跳出 [1/3, 3] 的近 3 年 839 处（599 个代码，样本 37 处），引擎会把它当成收益。量级：涨 389 处、跌 450 处；×3–5 与 ÷3–5 各占约三成，超过 10 倍的 72 处；收盘价不到 5 美元的占七成；2024 年起每年两三百处。逐项统计（2026-11-13）：落在整数比（2、3、4、5、8、10……及其倒数，±3%）附近的 198 处，占 23.6%，与把比值随机扰动后的基线（约 24.5%）相同，**没有向整数比集中**；跳变日之后的成交量中位数是之前的约 20 倍（拆并股应当反向变化），跳变多在盘中形成而不是开盘就到位。随机抽查 15 处（看前后各 5 个交易日的开收与成交量），13 处是真实暴涨暴跌的形状（盘中形成、成交量放大几十到上千倍、之后继续走或部分回落），2 处分不清，没有一处像漏记的拆并股；用「整数比 + 开盘即到位 + 成交量与价格反向变化 + 之后保持」最严的条件筛出 14 处，多为生物科技股的单日暴跌，凭记忆认出的几只是临床试验失败（未联网核实）。结论：绝大多数是真实行情，漏记拆并股的量级不超过几十处（1–2% 以内）。所以面板不按整数比自动执行拆并股（那会把真实暴跌改成中性），校验逐条列出、按规则登记。做小盘股研究时要么按成交额、价格过滤，要么把这些代码剔除前后各跑一遍。
20. **无因子退市前的几天**：最多 4 个没有因子的成交日不可交易，但收盘价照旧在 `close` 里，引擎的记账价会跟着场外收盘价走（清算金额不受影响，见第三节末）。
