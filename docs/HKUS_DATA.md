# 港股、美股数据

港股（港交所主板 + 创业板）和美股（纽交所、纳斯达克、美交所及场外）的原始库、「交易日 × 证券」面板、读取入口和独立校验。设计见 `docs/DESIGN.md` 6.1.3。交易规则（费用、每手、税）见 `docs/markets/hk_rules.md`、`docs/markets/us_rules.md`；回测档案由 `panelbt` 那条线做，本文只管数据。

本文的数字都来自 2026-11-13 在开发数据根 `data/dev/hkus/` 上的下载：两地「全部证券近 3 年」（港股 2023-11-13 至 2026-11-12，美股至 2026-11-11）加「2010 年起的 200 只样本」。

## 最短例子

```bash
R=/path/to/root
python -m ashare.data --root $R --market hk sync-overseas --start 2023-11-13 --end 2026-11-12 --datasets hk_calendar hk_securities
python -m ashare.data --root $R --market hk select-sample-overseas --asof 2026-11-12   # 抽 2010 年起的样本，写 sample.json
python -m ashare.data --root $R --market hk sync-overseas --start 2023-11-13 --end 2026-11-12
python -m ashare.data --root $R --market hk build-overseas                   # 近 3 年全部证券
python -m ashare.data --root $R --market hk build-overseas --universe sample # 2010 年起的样本
python -m ashare.data --root $R --market hk verify-overseas                  # 报告在 <root>/hk/reports/overseas_verify.md，不通过时退出码非零
```

美股把 `hk` 换成 `us`。

```python
import ashare.data as ad

hk = ad.open("/path/to/root", market="hk")                   # 默认 universe="all"
p = hk.panel(["close", "adj_factor", "connect_eligible"], start="2025-01-02")
p.dates, p.symbols, p["close"]                                # T×N 只读数组（港元）
hk.securities().collect()                                     # 证券表（含当前每手 board_lot_current）
hk.fx("USDHKD").collect()                                     # 汇率日线

us = ad.open("/path/to/root", market="us", universe="sample") # 2010 年起的 200 只
us.panel(["close", "split"], symbols=["AAPL"])["split"]
```

数据根：港股写在 `<root>/hk/`、美股写在 `<root>/us/`，各有一份清单，与 A 股的 `<root>/cn/` 互不相干。A 股的同步计划、`required`、`status`、`verify` 报告、内容版本、面板版本在同一个根下加入港美股（含未完成、失败的分区）前后逐位相同（`test/data/test_hk_isolation.py`）。

## 一、数据权限实测（2026-11-13）

每个接口先用一次最小的只读请求试，再对主要接口各做一次 25 次、两个接口各 150 次的顺序突发（不并发）。没有遇到限流（code 40203）：150 次请求在 12–18 秒内全部成功，即至少每分钟 500 次不限；更高的上限没有去试。正式同步按每接口每分钟 200 次、每个数据集 2 个并发，全程没有触发退避。

## 二、数据集与时点

原始数据集登记在 `catalog.OVERSEAS_DATASETS`（不并入 A 股的 `DATASETS`），原始字段保留 Tushare 原名，每个分区一个不可变 Parquet 修订：

| 数据集 | 接口 | 分区 | 时点 |
|---|---|---|---|
| `hk_calendar` / `us_calendar` | `hk_tradecal` / `us_tradecal` | 一个分区（1980 至明年年底） | 交易所提前公布；风球、临时休市只在事后体现 |
| `hk_securities` | `hk_basic` | 按状态 L/D/P | 当前主表；名称、每手是现值 |
| `us_securities` | `us_basic` | 一个分区 | 当前主表 |
| `hk_daily` / `us_daily` | 日线 | 按交易日 | 收盘后（港股约 18 点、美股次日早上） |
| `hk_adjfactor` / `us_adjfactor` | 复权因子 | 按交易日 | **前复权快照**：每次除权都改写整段历史，只在同一次同步里可比 |
| `hk_daily_hist`、`hk_adjfactor_hist`、`us_daily_hist`、`us_adjfactor_hist` | 同上 | 按证券（样本，2010 年起） | 同上；每只证券一次取完 |
| `hk_connect_sh`、`hk_connect_sz` | `stock_hsgt` | 按交易日 | 当天名单，2025-08-12 起 |
| `hk_connect_hold` | `hk_hold` | 按交易日 | 日终持股，次一交易日公布 |
| `overseas_fx_daily` | `fx_daily` | 按货币对 | 见「汇率」 |
| `overseas_fx_midrate` | `fx_midrate` | 按货币对 | 北京时间 9:15 公布 |

**前复权快照的处理**：两地因子都以最新交易日为 1，某天除权后此前整段历史被一起缩放，两次同步取的两天不能相除。所以因子数据集每次同步都在请求范围内整段重抓，每个分区记同一个 `snapshot`；面板构建要求区间内快照唯一，否则报错（`test_snapshot_mismatch_rejected_then_full_refresh_fixes` 模拟「只补新日子」时第 20 天的派息让旧段整体缩放，构建被拒）。代价是每次增量都要重抓全部因子分区（见第六节的估算和建议）。

## 三、面板字段

两套代次：`all`（按交易日的全部证券，开发库为近 3 年）和 `sample`（2010 年起的 200 只）。存储写法同 A 股面板（`<root>/<市场>/panel_<universe>/<版本>/<字段>.npy`，`current.json`）。同名字段与 A 股面板含义和单位相同：价格是每股交易币种元，成交量是股，成交额是交易币种元。A 股专有的涨跌停、ST、行业、指数权重、估值字段不提供。

| 字段 | 单位 | 两地 | 口径 |
|---|---|---|---|
| `open` `high` `low` `close` | 交易币种元/股 | 都有 | 不复权。港股 2020-07-02 至 2023-12-29 的收盘价改用因子表的精确值（`close_price`，相差不超过半分时），开高低价仍是四舍五入后的值；美股非正价格（无成交日源写 0）记为缺失 |
| `previous_close` | 同上 | 都有 | **两地不同**：港股是除权除息后的参考价，美股是上一日原始收盘价 |
| `volume` | 股 | 都有 | 港股是交易所全日成交量；美股与公开的综合成交量一致（AAPL 2024-01-02 为 82488674 股），是否含盘前盘后源没写 |
| `amount` | 交易币种元 | 都有 | 港股币种看证券（人民币柜台为人民币，见已知问题）；美股美元，2016 年前多为空 |
| `vwap` | 交易币种元/股 | 都有 | 美股取源的 `vwap`，港股为 `amount / volume` |
| `adj_factor` | 倍 | 都有 | 前复权快照换算成后复权：区间内每只证券第一个有因子的交易日为 1，只有比值有意义。港股含现金分红、拆并股、供股；美股只对部分证券含现金分红（见第四节） |
| `action_ratio` | 倍 | 都有 | 因子比 r = F[t]/F[t−1]，无事件为 1，无因子为 NaN |
| `split` | 倍 | 都有 | 识别出的拆并股比例（每股变成几股），其余为 1；`action_source=3` 时为 r |
| `equivalent_cash` | 交易币种元/股 | 都有 | `action_source=2` 时的等效现金 = 上一个收盘价 ×（1 − 1/r），其余为 0 |
| `action_source` | 枚举 | 都有 | 0 无事件，1 拆并股，2 分不出现金与股数的调整，3 因子下调且非整数比 |
| `has_quote` | 布尔 | 都有 | 源当天有日线（港股停牌日、无成交日都不出行） |
| `tradable` | 布尔 | 都有 | `has_quote` 且成交量 > 0 |
| `is_listed` | 布尔 | 都有 | 港股按证券表上市日（含）至退市日（不含）；美股按区间内首个至末个有行情的交易日（事后推断） |
| `delist` | 布尔 | 都有 | 港股为退市日或其后首个交易日；美股为末个行情之后的首个交易日，且末个行情早于区间终点 20 个交易日以上（事后推断） |
| `connect_eligible` | 布尔 | 港股 | 当天在港股通（沪或深）名单里；2025-08-12 前恒为 False |
| `connect_sell_only` | 布尔 | 港股 | 不在当天名单、但上一交易日南向有持股：只能卖出 |
| `connect_known` | 布尔 | 港股 | 当天两份名单分区都已完成（2025-08-12 起） |
| `connect_held` | 布尔 | 港股 | 南向日终持股大于 0（2017-03-17 起） |
| `price_rounded` | 布尔 | 港股 | 源四舍五入期内、收盘价低于 0.5 港元（最小价位小于 0.01）的格 |
| `total_market_cap` | 美元 | 美股 | 源 `us_daily.total_mv` |

证券表（`securities()`）：代码、名称、板块或类别、上市退市日、币种、区间内首末行情日；港股另有 `board_lot_current`（当前每手）、`currency_source`（源币种），美股另有 `exchange`（因子表里最后出现的交易所）、`code_reused_in_basic`（证券表同一代码多行）。

汇率（`fx(pair)`）：FXCM 的 `USDHKD`、`USDCNH`（港股根）和 `USDCNH`（美股根）给 bid/ask 收盘及中间价 `close`；人民币中间价 `CNYHKD`、`CNYUSD` 给 `rate`（1 单位外币兑人民币，源值 ÷ 100）。

## 四、公司行为：只知道总的调整比例

两地都没有分红送转、拆并股的事件明细接口，只有前复权累计因子。面板只用相邻两个有因子的交易日之比 r = F[t]/F[t−1]：

- |r − 1| ≤ 1e-5：源因子只留 6 位小数造成的舍入噪声，不算事件。
- r 或 1/r ≥ 1.05、且与某个 p/q（q ≤ 10、p ≤ 1000）的相对差在 2e-4 以内（r < 1 时另放宽到绝对差 6e-5，港股合股比在源里只留 4 位小数，1/12 写成 0.0833）：**拆并股**，`split = p/q`，`action_source = 1`。
- 其余 r > 1：**分不出现金与股数**（现金分红、特别派息、供股、公开发售、分拆、送股与派息同日），`action_source = 2`，`split = 1`，`equivalent_cash = 前收 × (1 − 1/r)`。港股这个值与源的前收一致（腾讯 2024-05-17 派 3.40 港元，r = 0.979929/0.971537，前收 393.6 = 397.0 − 3.4）。
- 其余 r < 1 且非整数比：`action_source = 3`，`split = r`，未解释（港股近 3 年 0 格，美股 167 格）。

识别结果（近 3 年全部证券）：港股拆并股 300 格、分不出 4717 格；美股拆并股 2306 格、分不出 21899 格、下调非整数比 167 格。

**美股的因子口径不一致**：实测 `us_adjfactor` 对一部分证券含现金分红、对另一部分不含。近 3 年有 200 个以上交易日行情的证券中，纽交所 2322 只里 1081 只、纳斯达克 4873 只里 822 只出现过分红类调整；样本里的大票：JPM、KO、NVDA、GOOGL（2024 年起派息）含，AAPL、MSFT、XOM、WMT 不含。同一代码还常有两条交易所序列且口径不同（WMT 的纽交所序列含分红、纳斯达克序列只含拆股），面板每只证券只取一条（非场外优先、天数多的优先、再按字母序）。所以**美股的 `adj_factor` 不能当总收益因子用**；建议美股只用 `action_source = 1` 的拆并股（`split`）调整持股，把收益看作价格收益，分红另找来源。

**拆并股识别抽查**（样本面板，与公开事实核对）：AAPL 2014-06-09 7 拆 1、2020-08-31 4 拆 1；AMZN 2022-06-06 20 拆 1；GOOGL 2022-07-18 20 拆 1；NVDA 2021-07-20 4 拆 1、2024-06-10 10 拆 1；TSLA 2020-08-31 5 拆 1、2022-08-25 3 拆 1；KO 2012-08-13 2 拆 1；WMT 2024-02-26 3 拆 1；腾讯 2014-05-15 5 拆 1：日期和比例全部与公开事实一致。另有 MSFT、JPM、XOM 区间内没有拆股（相符）。Tushare 的因子里没有像 Yahoo 那样把分拆（spin-off）写成非整数「拆股因子」的问题，分拆会落进 `action_source = 2`。港股 1.1（10 送 1）、16/9、29/8 这类比例被识别为拆并股，其中可能混有供股，只能确定是「股数按这个比例变」的等效调整。

**对回测的影响与建议**：`panelbt` 需要区分「股数变化」和「现金」。

- `action_source = 1`：按 `split` 调整股数，没有现金；可靠。
- `action_source = 2`：两种保守处理任选其一并在研究里写明。（a）按等效现金记账：每股派 `equivalent_cash`，扣投资者适用的股息税（港股通 20%，港股非 H 股 0%、H 股 10%）；供股、分拆会被当成现金，高估流动性但金额正确。（b）按等效股数再投资：股数 × r、没有现金、不扣税，相当于税前分红无损再投资，高估税后收益约「股息率 × 税率」。默认建议（a），税率按档案。
- 美股 `action_source = 2` 只覆盖部分证券，任一种处理都会让有无分红的证券口径不同；严格研究只用拆并股。
- 公司行为的裁决用的是当天收盘后的因子，只能按事件在除权日开盘调整持仓，不能当盘前信号用。

## 五、校验（`verify-overseas`）

与同步、面板构建不共用代码，按清单直接读原始 Parquet。每项判 `pass` / `explained` / `fail` / `info`；「已解释」只认已知例外清单 `src/ashare/data/overseas_known_exceptions.json`（逐条写市场、检查项、匹配键和原因编号；按规则登记的条目不写代码，覆盖一类不符；不放任何由行情算出的数值，测试按白名单核对键集合）。清单外的不符一律 `fail`，命令行退出码非零；清单里有、本次没用到的条目列为过期；「原因未查明」的原因单列计数。面板部分不允许例外。

检查项：清单对文件（状态、文件、哈希）；日历自洽（开市日的 `pretrade_date` 是上一开市日）；日分区覆盖（缺分区、空分区、整页且没再翻页、休市日有分区）；主键唯一（分「同值重复」「取值冲突」）；日线取值范围；因子表收盘价与日线一致（分「半分以内」「超过半分」）；因子快照唯一；因子事件与价格（港股 r 应等于上一日收盘价 / 前收，容差 0.5% 或一个价位；美股拆并股日价格应有相应跳变，只核对相邻两个交易日都有日线的事件）；港股上市期与行情；休市日有行；样本历史与按日分区在重叠日上逐值相同；面板（抽 2000 格核对收盘价、成交量、`has_quote`，抽 300 只核对后复权因子比、枚举越界、上市期外行情计数）。信息项：开收盘价在最高最低之外、单日涨跌超过 3 倍而因子不变、代码复用线索、港股每手是否可得。

## 六、已知问题与专门查过的坑

1. **港股日线四舍五入**：`hk_daily`（`hk_daily_adj` 也一样）在 2020-07-02 至 2023-12-29 把全部价格四舍五入到 0.01，此前此后都保留 0.001。低价股失真严重（0.017 写成 0.02）。面板收盘价改用因子表的 `close_price`（相差不超过半分时，近 3 年 17144 格、样本 26769 格），开高低价和前收没有精确来源，由 `price_rounded` 标记。
2. **港股代码复用**：证券表用 `代码!.HK` 记已退市的旧公司，日线却把新旧公司都写成 `代码.HK`（00638、00668、00800、02698、06600 在近 3 年里都有）。面板把新公司上市日前、旧公司退市日前的行改记到 `代码!.HK`（近 3 年 630 行、样本 15853 行）。
3. **港股停牌日、无成交日没有日线**（因子表照常有行，一天约 500 只只在因子表里）：`has_quote` 分不出停牌与无成交。源没有停牌表。
4. **港股每手**：`hk_basic.trade_unit` 只有当前值（11 只为空），没有历史；合股、拆股常伴随每手变更，用当前值回测历史会算错可买手数。
5. **港股人民币柜台**：`8xxxx.HK`（名称带「-R」）是人民币柜台，价格和成交额是人民币，但 `curr_type` 也写 HKD；证券表共 25 只。证券表的 `currency` 对「8xxxx.HK 且名称以 R 结尾」的改为 CNY（源值保留在 `currency_source`），面板价格不换算。
6. **港股通名单**只从 2025-08-12 起有；此前只能看南向持股（2017-03-17 起），「持有」不等于「合资格」。2025-08-12 前的港股通回测没有可靠的标的池。
7. **美股代码复用与改名**：证券表 106 行重复代码（如 ABX 先后是巴里克黄金和 Abacus），日线同一代码同一天有两行（同值 1.95 万行、取值冲突 348 组），因子表同一代码常有两个交易所两条序列。源没有永久证券编号；面板按代码拼接，长缺口后重新出现的代码（校验的「代码复用线索」）可能是另一家公司。
8. **ADR 与普通股混在一张表**：`us_basic.classify` 分 EQ/ADR/GDR/PF，日线里不区分；证券表有 `kind` 列。
9. **美股日线是否含盘前盘后**：源文档没写；AAPL 2024-01-02 的成交量 82488674 股、收盘价 185.64 与公开的常规时段综合数据一致（与记忆核对，未联网复核），开收盘价应为常规时段，未核实盘前盘后成交是否计入成交量。
10. **美股没有上市退市日**：`us_basic` 只有 1 行退市日、上市日多为空；`is_listed`、`delist` 由行情推断，带后见之明；退市后的场外交易和退市收益没有。
11. **美股因子覆盖**：2006 年起才有；2026-08-31 起不再给 ARC、BTS 和场外（每天约 7100 行，此前约 1.47 万），清单里该日分区经人工确认；口径不一致见第四节。
12. **两地日线的成交额币种**：港股是交易币种（绝大多数港元，人民币柜台为人民币，少数美元柜台未见）；美股美元。
13. **汇率时点**：`fx_daily` 的日期是格林尼治日期，源没写 K 线在哪个时刻切分。实测 USDCNH 有 629 根周日 K 线、198 根周六 K 线，周五只有 585 根（周一至周四约 765 根），推断多数年份以纽约 17:00 切分、按开盘时的格林尼治日期标注（未核实），与港股收盘（香港 16:00）、美股收盘（纽约 16:00）都不在同一时刻。人民币中间价是北京时间 9:15 公布。做币种换算建议用中间价并在研究里写明时点。
14. **美股 2026-11-12 的分区**：同步时源还没发布，两个分区被空表保护标为可疑；源发布后重跑 `sync-overseas` 会补上（这会整段重抓美股因子）。

**两地大票抽查**（与记忆中的公开收盘价比，未联网复核）：AAPL 2024-01-02 收 185.64、MSFT 同日 370.87、NVDA 2024-06-10 收 121.79、TSLA 2022-08-25 收 296.07、AMZN 2022-06-06 收 124.79、GOOGL 2022-07-18 收 109.03、WMT 2024-02-26 收 59.60：与记忆一致。KO 2024-01-02 收 59.82、JPM 172.08、XOM 102.36，腾讯 2024-01-02 收 296.6、汇丰 62.95、中国移动 64.25、港交所 262.4、友邦 65.65，腾讯 2014-05-15 拆股后收 108.8：未核实（记不准）。拆股日见第四节，全部相符。

建议：

1. 因子增量改为「按证券触发重抓」：每次只抓最近几天的因子分区，和库里同一天的旧值比较，有变化（发生了除权）的证券单独按证券重抓整段历史，存成按证券的分区；面板因子一律从按证券的分区来。这样每次增量只多几十次请求。
2. 美股分红另找来源（SEC 文件、付费数据），或研究只用价格收益；`panelbt` 美股档案的总收益要等分红来源。
3. 港股通 2025-08-12 前的名单要从沪深交易所的调整公告重建，或者只从 2025-08-12 起做港股通视角的研究。
