# 港股与美股市场档案（`panelbt.markets`）

2026-11-13 首版。三份档案：**香港本地账户** `HK_DIRECT`、**港股通**（内地个人经沪深港通南向）`HK_SOUTHBOUND`、**美股** `US`。规则依据是同目录的两份调研 [hk_rules.md](hk_rules.md)、[us_rules.md](us_rules.md)，下文「出处」一栏写的是调研文档里的小节号；调研标「未核实」的条目这里照它的最佳判断取值，并原样保留「未核实」。

代码：`packages/panelbt/python/panelbt/markets/hk.py`、`us.py`；测试：`test/test_markets_hkus.py`。

## 1. 用法

```python
import numpy as np
import panelbt as bt
from panelbt import markets

prices = np.array([[50.0, 8.0], [52.0, 8.2], [55.0, 7.9]])
dates = ["2026-03-02", "2026-03-03", "2026-03-04"]
targets = bt.Targets.from_dense([[0.5, 0.5], [np.nan, np.nan], [0, 0]])
sb = markets.get("hk_southbound")          # "ashare" / "hk_direct" / "hk_southbound" / "us"
config = sb.config(lot_sizes=[500, 2000], initial_cash=1e6)
result = bt.run(sb.market(prices, prices), targets, sb.costs(dates), config)
```

- `markets.get(name)` 按名字取档案，`markets.PROFILES` 是全部名字；`markets.get("ashare")` 就是原来的 `ASHARE` 对象（同一个对象）。注意要写 `from panelbt import markets`（或 `import panelbt.markets`）；`panelbt/__init__.py` 不在这次可改范围内，单写 `import panelbt as bt` 时 `bt.markets` 还不存在。
- `costs(dates, **覆盖)` 与 A 股档案用法一样：按日期展开费率表，任何关键字覆盖最终值（含佣金）。另有 `fill_value=`（见第 4 节）和港股通的 `fx_cost=`。
- `config(**…)`：港股要给 `lot_sizes`（每证券，长度 N 或 T×N）；美股给 `n`（默认整股，`fractional=True` 允许碎股）。分红扣税、退市处理见第 2 节；把行情的 `cash_div` 也传给 `config`，分红税只看当天派息的证券。允许做空时必须写 `delisting=`。
- `market(exec_price, close, suspended=…, connect_eligible=…, can_short=…, …)`：两地都没有涨跌停；港股通用 `connect_eligible`（T×N，按时点）挡住不在名单内的买入，持有的只能卖出。
- 保证金账户：`markets.hk_margin(...)`（比例必须由调用方按券商给）、`markets.reg_t_margin(financing_rate=...)`（美股 Reg T 默认值）。港股通不能融资融券，`config` 遇到允许做空或融资的保证金模型会报错。
- 档案外的小工具：`markets.home_currency_nav(nav, fx)`、`markets.connect_home_equity(equity, cash, fx, initial_cash)`、`markets.net_dividends(cash_div, rates, account)`、`markets.settlement_days(dates)`。

## 4. 内核表达不了的逐笔规则：怎么近似

内核的费用只有「按金额比例 + 按股」两种（按日期变化），佣金另有每笔下限和上限比例，**没有「每笔固定金额」、也没有单项费用的每笔下限、上限和取整**。处理办法：

- **能表达的直接用**：佣金的每笔下限与上限（美股 $1 / 1%，港股平台费 HK$15 用「费率 0、下限 15」表达，恰好等于每笔固定 15）。
- **每笔固定金额、单项下限、向上取整**：按参考成交额 `fill_value` 折成比例费，加在对应费率上：
  - 港股：使用费 HK$0.5 + 交收费下限超出部分 `max(2 − 0.002% × fill_value, 0)` → `fee_rate`；印花税取整按最坏情况每笔 +HK$1 → `tax`。
  - 美股：SEC 费、TAF 按笔向上取整到分，最坏每项每笔 +$0.01 → `fee_rate_sell`（该项费率为 0 的时段不加）。
  - 成交额等于 `fill_value` 时，折算后的比例费正好等于逐笔规则的上限（测试 `test_fill_value_converts_fixed_charges`）。偏差方向要按费用项分开看：
    - 每笔固定额（使用费 HK$0.5）：单笔大于 `fill_value` 多收，小于则少收。
    - 交收费下限：真实收费是 `max(0.002%×A, 2)`，近似是 `2A/fill_value`。单笔大于 `fill_value` 一律多收（真实规则在 HK$10 万以上下限已不起作用，近似仍按 2/20,000 = 0.01% 收，比真实 0.002% 多约 0.008%，单笔越大多收的金额越多）；小于则少收。
    - 印花税取整：真实每笔多出 [0, 1) 港元，平均约 0.5；近似按 `A/fill_value` 加。相对上限，单笔小于 `fill_value` 时少加；相对平均值，单笔大于 `fill_value` 的一半就多加。所以小单合计未必少收：复核人的例子里一笔 HK$16,600 的卖出（2025-06-27，港股通），近似比真实逐笔规则多 0.09 港元，多加的印花税抵过了少收的交收费下限。
    - 默认取偏小的值（港股 HK$20,000、美股 US$10,000），用户应改成自己策略的典型单笔成交额；`fill_value=None` 只算法定比例部分。
- **单项每笔上限**：忽略，等于多收（悲观）。
- **征费到仙的四舍五入**：期望为 0，不建模。

| 规则 | 近似 | 偏向 | 典型量级 |
|---|---|---|---|
| 港股印花税每笔向上取整到 HK$1 | +HK$1 / `fill_value` | 相对上限：成交 ≥ fill_value 时多收；相对平均（HK$0.5）：成交 > fill_value/2 时多收 | HK$20,000 一笔：0.005% |
| 交易系统使用费 HK$0.5/笔（2023 年前） | +0.5 / `fill_value` | 成交 > fill_value 多收，< 则少收 | HK$20,000：0.0025% |
| 交收费每笔下限 HK$2（2025-06-30 前） | 超出部分 / `fill_value` | 成交 > fill_value 多收，< 则少收 | 默认值下对所有成交加 0.008%。真实规则在 HK$10 万以上不起作用，近似仍多收约 0.008%，单笔越大多收越多 |
| 交收费每笔上限 HK$100（2025-06-30 前） | 忽略 | 多收（悲观） | 只对 HK$500 万以上的单笔：HK$1,000 万一笔多收 HK$100（0.001%） |
| FINRA TAF 每笔上限 | 忽略 | 多收（悲观） | 2026 年费率下单笔超过 50,205 股才封顶；10 万股一笔多收 $9.71 |
| TAF「成交价低于费率时按成交额收」 | 忽略 | 多收（悲观） | 只影响价格低于 $0.0002 的成交，可忽略 |
| SEC、TAF 向上取整到分 | +$0.01 每项 / `fill_value` | 成交 ≥ fill_value 时偏悲观 | US$10,000：0.0002% |

## 5. 不模拟的规则

港股（hk 11.2）：
1. 港股通按逐笔成交取整、香港按成交单据取整的差别（统一按第 4 节近似）。
2. VCM 冷静期价格带、收市竞价 ±5%、开市竞价不平衡：日线无法判断能否按开收盘价成交。
3. 碎股市场的折价与流动性：引擎允许按全价卖出全部零股（偏乐观）。
4. 港股通的参考汇率 ±3% 冻结资金、股息换汇时点（只有成交的汇兑损耗按 `fx_cost` 计）。
5. 需要投资者决定的公司行为：供股认购、以股代息选择、收购要约。
6. 恶劣天气休市（2024-09-23 前）：由交易日历体现。
7. 南向每日额度。
8. 卖空的「不低于最佳卖价」规则。
9. 港股通证券组合费（年 0.008%，按持仓市值）：少收，量级每年 0.8 个基点。

美股（us 11）：
1. LULD 盘中暂停、全市场熔断（Level 3 2010 年以来未发生）。
2. Rule 201 卖空提价规则。
3. 现金账户的未交收资金限制（free-riding）：**按保证金账户的资金可用性模拟**——卖出所得当天即可再买入；现金账户每天全仓换股的策略会因此偏乐观。
4. PDT（2026-06-04 前保证金账户权益不足 $25,000 时滚动 5 日最多 3 次日内回转）：日频调仓不做同日买又卖，不触发；2026-06-04 起已取消。
5. 盘前盘后与夜盘、收盘竞价参与度、odd lot 报价。
6. 借券可得性与召回、Rule 204 强制平仓。
7. 分拆、换股收购等要发放新证券的公司行为（需数据层给事件）。
8. 多币种：一次回测只用美元。
9. PTP 卖出总价款 10% 预扣：应从股票池里排除。
10. ADR 存托费（常见 $0.01–$0.05/ADS/年，调研建议默认 $0.03）：不模拟，少收；股价 $30 的 ADR 约每年 0.1%。

## 7. 「以港币回测再折算」与内地投资者真实收益的差别

港股通档案以港币回测（负责人裁决）。`connect_home_equity(equity, cash, fx, initial_cash)` 把结果折成人民币：港股通投资者的现金一直是人民币，只有每天成交、费用、分红带来的现金变动按当天汇率换汇，所以把每天港币现金的变动按当天汇率折算累加，持仓市值按当天汇率折算。汇率用中间价，买卖的结算汇兑价差已经由 `costs` 里的 `fx_cost`（每边比例成本）计入回测。

仍然存在的差别：
1. 引擎里闲置现金是港币；按目标权重定仓用的是港币权益。人民币对港币涨跌时，真实投资者可买的港币数量会变，回测不反映（汇率每变 1%，下一次调仓的规模差 1% × 现金占比）。
2. 结算汇兑比率是全市场轧差后的实际成本，`fx_cost` 是一个常数假设（默认每边 0.05%，调研没有给出数值，**待核实**）。
3. 参考汇率 ±3% 冻结资金：真实账户可用资金比回测少约 3% × 买入金额，满仓策略可能买不足。
4. 分红到账晚、在香港换汇后再扣税：按除息日到账、按当天汇率折算，时点有偏差。
5. 价差所得暂免个税（至 2027-12-31）以后若恢复，回测不反映。

香港本地账户和美股的投资者现金就是港币、美元，用 `home_currency_nav(nav, fx)` 直接按汇率折算即可（不含换汇成本）。

## 10. 与调研建议不一致的地方

1. 调研建议「默认取 IBKR Fixed 佣金」只针对美股；港股调研说佣金「参数化，不写死」。为了十行内能跑起来，港股两份档案也带了默认佣金（标为假设，`costs` 里可覆盖）。
2. 调研建议港股通的汇兑损耗「折成费用或另做换算」；任务书要的是档案外换算工具加双边比例成本。成本放在了 `HK_SOUTHBOUND.costs(fx_cost=)` 里（每笔成交按金额收，与真实的结算汇兑比率形式一致，也不会和换算工具重复扣），换算工具只做汇率折算；默认值调研没有给出，是假设。
3. 调研建议美股取整「按笔向上取整到 $0.01」、港股印花税每笔取整：内核做不到，改为第 4 节的参考成交额折算。
4. 调研建议港股 H 股按证券扣税：内核只有按日的税率，改为每天取最高税率（悲观）并提供 `net_dividends` 的精确替代。
5. 调研建议美股空头维持保证金 max(30%, $5/股)：只能统一 30%。
6. 调研建议「建议引擎支持分拆/换股事件后再上线美股档案」：这次照任务书上线档案，分拆等写进不模拟清单。
7. 调研建议 ADR 存托费默认 $0.03/ADS/年：内核没有按持股的定额费用，不模拟（列入能力清单）。
8. 港股本地借券费调研没有水平，借用了美股的年 0.3%。
9. 调研 6.1 表说中国居民企业红筹经 HKSCC 代理人持有时按 10% 预扣，11.1 的建议只写了「非 H 股 0%」。首版跟了 11.1；返工后加了可选的 `resident_enterprise` 标记，默认仍按 0%（偏乐观，列入第 9 节待确认）。
