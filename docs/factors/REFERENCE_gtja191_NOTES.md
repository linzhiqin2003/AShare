# 国泰君安 191 参考实现：疑点、处理与冒烟结果

> **已改（2026-11-13，R-G-02）：149 在股票自己当天收益（公式里的 `CLOSE/DELAY(CLOSE,1)-1`，筛选前）为 NaN 时输出 NaN**，即停牌日和复牌首日为 NaN；开头不足 252 行时用已有的行、有效配对 ≥ 20 出数不变。重跑冒烟：300 日与 1010 日两次，落在无收盘价格子上的值都从 5483、36689 格降为 0。

参考实现在 `src/ashare/factor/alphas/reference/gtja191_ref.py`（186 条，每条一个函数，函数上方注释是 `sources/gtja191.jsonl` 的 `formula` 原文），算子在 `gtja191_ref_ops.py`，测试在 `tests/reference_gtja191/`（算子手算例子与朴素循环对拍、整体运行、pandas 抽查），冒烟脚本 `tests/reference_gtja191/smoke_gtja191_ref.py`。

写的时候只读了 `CONVENTIONS.md`、负责人裁决（2026-11-13）、`REFERENCE_INPUTS.md`、`sources/`、取数模块和核对工具的参考实现接口。`REFERENCE_INPUTS.md` 第 2 节说「国君疑点条目按 DSL_REFERENCE 第 6 节的『怎么翻』实现」，但这份工作不许读 `DSL_REFERENCE.md`，所以疑点一律按 `CONVENTIONS.md` 4.2 节的建议加负责人裁决处理；若两份文件的「怎么翻」有出入，核对时会以「不一致」暴露出来。

## 1. 口径落实

| 项目 | 做法 |
|---|---|
| 输入 | `reference_frames` 的字典；`RET` 用 `returns`（上市首日 NaN，D-03）；`BANCHMARKINDEXOPEN/CLOSE` 用 `benchmark_open/close`（按名字取，Q-G-D1），作为 T × 1 列与股票广播 |
| 逐元素运算 | NaN 传播；除法、幂、对数的非有限结果为 NaN；`MAX/MIN(A, B)` 两个参数是序列或 0 时用 `np.maximum/minimum` |
| 比较、`&`、`||` | 1.0 / 0.0，任一侧 NaN 为 NaN，不短路 |
| `?:` | 条件 NaN 为 NaN；只看被选中的分支 |
| 滚动窗口 | 窗口必须满（窗口内任一 NaN 即 NaN），含当天，按行数计；全部用 `sliding_window_view` 对每个窗口直接算（两遍法），不用在线递推 |
| `RANK` | `rank(axis=1, pct=True)`，平均秩 / 有效个数 |
| `TSRANK` | （严格小于的个数 + (相等个数 + 1) / 2）/ n |
| `STD`、`COVIANCE` | 分母 n−1；`STD` 在窗口内数值逐个相等时给精确的 0 |
| `CORR` | 两遍法 Pearson；任一侧窗口内数值逐个相等时为 NaN（按 `max == min` 判断，不用容差） |
| `DECAYLINEAR` | 权重从最早到今天 1..d，除以权重和 |
| `WMA` | 权重 0.9^i（今天 i = 0），除以权重和 |
| `HIGHDAY/LOWDAY` | 距今天数，今天为 0，并列取最近一次 |
| `SMA(A, n, m)` | `(m·A + (n−m)·Y_prev) / n`；首个有效值作初值；当天 NaN 输出 NaN、状态不变；累计有效值 ≥ n 才出数 |
| `COUNT`、`SUMIF` | 条件（和 A）在窗口内都要有效；全假时 `SUMIF` 为 0 |
| `REGBETA(A, SEQUENCE(n), n)` | 对 1..n 加截距回归的斜率，窗口必须满 |
| `FILTER` | 条件为假或 NaN 的样本为 NaN |
| 149 的 `REGBETA` | 252 行窗口内两边都有效的配对 ≥ 20 才出数（Q-G-149 裁决）；面板开头不满 252 行时窗口只含已有的行；自变量在有效配对上逐个相等时为 NaN；股票当天收益为 NaN 时输出 NaN（R-G-02） |

## 5. 冒烟结果

两次运行：最近 300 个交易日（不带预热）和核对区间规模 1010 日（750 + 260 预热）× 5923 只，2026-11-13 的面板，机器负载 7–8。有效格比例的分母是当天有收盘价的格子；「不同取值数」是整张结果里有限值的去重个数（≥ 1e6 记作 ≥1e6）。

- **报错、全 NaN、全常数：都没有**（两次运行都是 0 条）。
- 取值很少的条目都是公式本身的离散输出：004（±1）、056、101、123、148、154（比较，0/1）、053、058、182（计数 / n）、103、177（`HIGHDAY/LOWDAY` 的 20 档）、075（计数之比）。
- 有效格比例低的条目：
  - 138（300 日 0.6%，1010 日 0.9%）：口径导致。`TSRANK(MEAN(VOLUME,60),17)` 在 5 日窗口内常数的格子占 27%（60 日均量很平滑，17 日排名常年为 1），`CORR(…, 5)` 因而 59% 为 NaN；之后 `TSRANK(·,19)`、`DECAYLINEAR(·,16)`、`TSRANK(·,7)` 都要窗口满，要连续约 40 天的相关系数都有效，实测逐层剩 6.1%、1.2%、0.6%。140、121 有同样的机制，程度轻些。
  - 025、026、033、039、092、098、184：长窗口（250、230、240、≈216、≈211、200、200）在 300 日的数据上只有最后几十天能出数，1010 日上正常。
  - 087：分母 `OPEN-(HIGH+LOW)/2` 为 0 的格子为 NaN。
- 合成数据上（12 只股票）064 全为 NaN：小截面里 `RANK(MEAN(VOLUME,60))` 的 4 日窗口约四分之一是常数，`CORR` 为 NaN，再经 `TSMAX(·,13)`、`DECAYLINEAR(·,14)` 传播；真实面板上 064 有效格 68%（300 日）。

### 耗时

1010 日 × 5923 只全部 186 条合计 173.5 s，单条最长 11.1 s，都在一分钟以内。最慢的十条（1010 日）：149（11.1 s；按 R-G-02 修改后重跑 10.9 s，252 行回归逐窗口两遍）、184（4.5，`CORR` 窗口 200）、119（4.2）、064（4.0）、140（3.9）、130（3.8）、101（3.7）、179（3.6）、056（3.2）、026（3.1，`CORR` 窗口 230）。`SMA` 是逐日循环（每步对全部股票向量化），单次约 0.05 s。
