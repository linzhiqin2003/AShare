# C6 实现笔记

以 DESIGN 4.18 v5.1 为准。按用户裁决应用 `.review/design_v51.diff`，本 worktree 的4.18全节与主干7ccf6f1一致；未带入主干其他章节的无关变化。不修改引擎、C4回测适配器或其他worktree。真实数据只读复制至本worktree的 `tmp/crypto`，公开产物只含汇总与合成测试。

## 实现中的选择

- 季度信号使用独立原始对象、清单、内容版本与指针。每期列举全部月份，上市代理取全归档首行，不能随查询起点移动。
- v5.1的最后成交使用 `volume > 0`，按原始开盘时刻核对闭区间[交割−24小时，交割]。任意交割后的成交都不能被例外覆盖；有来源的上市时刻和交易所deliveryDate冲突照常报错。
- 收盘晚于交割的行自动登记为 `post_delivery`，逐期计数、范围、原因与规范化元数据进入版本哈希，原始字节与解析行完整保留。信号表剔除这些行；交割整点有成交的K线用于核对，但因收盘越界仍被剔除。不能手工覆盖自动例外。
- 当前4期未到期合约的最后成交下界核验标为 `pending_not_expired`。判断使用冻结构建终点与全部归档末时刻的较大者，不读取运行时钟；已到期不能靠缩短查询范围绕过核验。无归档且无上市证据仍按原设计列入排除清单，标为 `excluded_no_listing`。
- 连续相邻小时同收盘从第二小时起屏蔽，不回填首小时，以免使用未来冻结状态。非零成交的持平小时也保守屏蔽；缺小时须带原因登记，仍为缺值。
- 现有面板的成交、标记与指数质量位合并，按整行保守屏蔽，可能多损失正常的单种价格输入。
- 1B的Z与q均采用相同有效OLS样本域，保留原日历轴；确认项使用所有可能的一次内点加密格的并集，观察和功效共用更保守的完整规则。
- MDE主值用 `h*b*sd_x` 表示因子持续h日增加1个样本内标准差的效应，同时列出单次初始冲击 `b*sd_x*Σφ^j` 的范围，不将单日b直接当作h日回归斜率。
- 按本轮资源限制，模拟最多2进程，每进程1个数值库线程；每格始终4000次，零假设统计分布先预计算，功效只查表。

## 设计问题与裁决

- v5原文要求原始末根收盘不得越过交割，因此严格构建曾正确失败。全量审计发现46/50期有尾行，其中7期交割整点开盘那根仍有成交。审查人以v5.1裁决：核对最后成交开盘窗口，剔除交割后收盘行。本轮已按新设计解决，无需再等待许可。
- “最后成交”只可能在到期后最终核验；未到期状态按上述冻结覆盖边界明确标记。无上市证据的合约继续排除，不伪造交割通过结果。
- 1B样本域、功效换算与加密全集的实现明确化列于上节；没有修改统计检验设计或调整策略阈值。
- onecontext此前检索未命中；本轮历史数据库无法打开，直接以用户裁决、设计diff和冻结数据为依据。
- 全局worklog在工作区之外，本任务禁止写工作区外，阶段记录留在此文件。已用本worktree的venv执行make dev；Rust构建限制2任务。本环境 `nice -n 15` 返回 `setpriority: Operation not permitted`，命令保留，计算另限线程、进程和超时。
