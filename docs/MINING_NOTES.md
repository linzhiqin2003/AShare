# 因子挖掘：评估、搜索、台账与多重检验

设计见 `docs/DESIGN.md` 6.2.2。本仓库只放机制；挖出来的因子、试验记录、台账文件一律不进仓库（默认写到数据根目录下不入库的 `mining/`，`ASHARE_MINING_DIR` 或 `root=` 可指到私有仓库）。本文的例子和测试只用自编的玩具表达式和量价基础字段。

## 最短例子

```python
from ashare.factor.mining import Random, Split, mine
from ashare.factor.mining.synthetic import market

panel = market(t=900, n=150, strength=0.003)     # 合成行情，埋了一个已知信号
split = Split.recent(panel.dates, holdout_years=1, valid_years=1)
result = mine(panel, split=split, strategy=Random(n=60, seed=1), root="/tmp/mining-demo")
print(result.text())                              # 试了多少、去重、折算后剩多少
holdout = result.unlock_holdout(panel)            # 只能解锁一次，解锁记进台账
```

单个因子：

```python
from ashare.factor import Evaluator, evaluate_factor
report = evaluate_factor(Evaluator().evaluate(expr, panel), panel)
print(report.text())                              # report.to_dict() 只有基本类型
```

真实数据上 `panel = ashare.data.open().panel(FactorEvaluator.required_fields() + 字段)`，多头端用 `market=ashare.backtest.market_from_panel(data, panel=panel)`（按板块的整手规则）。评估和挖掘不依赖可选依赖组 `ml`（标签、台账在 `ashare.labels`、`ashare.ledger`，`ashare.ml` 从那里转出，接口不变）。

## 一、单因子评估（`ashare.factor.evaluate`）

`FactorEvaluator(panel, ...)` 准备一次（标签、股票池、行情、基准、市值段），`evaluate_many({名字: 面板})` 评估一批。

| 内容 | 口径 |
|---|---|
| 收益标签 | `ashare.labels.compute`（不依赖 ml 依赖组）：信号日 t 收盘后出信号，t+1 按成交价 `exec`（默认开盘，可选收盘、均价）买、t+1+h 卖，价格乘复权因子；买入日不可买（停牌、涨停、一字板，口径同 `market_from_panel`）的样本不进 IC；卖出日不可卖按当日价（`sell_blocked="price"`，偏乐观）。退市后没有价格的样本缺失。传入的行情（`market=`）的成交价必须就是面板的 `exec` 字段，否则报错，免得标签和多头端用两种成交价。 |
| 股票池 | 默认 `default_universe`（与 `ashare.ml.default_universe` 相同，测试守住）：已上市、非 ST、上市满 120 日、当天有行情。股票池外的因子值置缺失。 |
| Rank IC | 每个持有期（默认 1、5、20）的日截面 Spearman（`panelops`，收益排序只做一次；私有内核不在时退回公开的 `panelops.rank_ic`，结果相同、只提示一次）。均值、标准差、ICIR（日频不年化）。t 值 = 均值 / √(s²·h/n)、自由度 ⌊n/h⌋ − 1、单侧 Student t 的 p 值（`stats.overlap_t`）；不重叠的块少于 10 个时不给 p 值并写明原因。段内只用标签完整落在段内的信号日（t + 1 + h < 段尾）。为什么这样算见第四节。 |
| 分组 | `panelops.group_returns`（序数分组，默认 10 组）在筛选持有期上的平均收益；单调性 = 组号与组均值名次的相关；最高减最低。 |
| 多头端 | 最高组（默认前 10%，`top=N` 改为前 N 只）等权，初始资金默认 100 亿元（`capital=`，理由见「账户规模与最低佣金」），在固定的调仓日表（第 0、`rebalance`、2·`rebalance`…行，默认每 5 天）上选股，因子从哪天开始有值都对齐到这张表；`ashare.backtest.execution_targets` 错到下一行成交，`panelbt.run_batch` 一次跑一批（A 股历史印花税、过户费、佣金万 2.5 最低 5 元、滑点 5 bp）。指标从第一次成交那天算起：年化（几何）、基准年化、超额（日超额均值 × 252）、信息比率、夏普、最大回撤、年化换手、年化成本占净值比例，以及超额日序列的每期夏普、偏度、峰度和方差比 q（Bartlett 核 10 阶的长期方差 ÷ 普通方差，不低于 1；折算夏普用）。 |
| 基准 | 默认（`benchmark="universe"`）：用同一份行情、同样的调仓日表、同样的成交错位、可交易规则和费用，持有信号日股票池全体等权——也就是「前 100%」组合，跑一遍 `panelbt`、整次评估复用。这样多头端和基准只差选股，零假设下超额才接近 0。`benchmark="close"` 是旧口径（股票池等权、收盘到收盘、d−1 日在池内、不扣成本），只作对照；也可传长度 T 的日收益。 |
| 分年度、分市值段 | 每个日历年的 IC 与超额；按总市值把股票池三等分的 IC。 |
| 自相关 | `panelops.factor_autocorr`，滞后 1 和调仓间隔。 |
| 与已有因子的相关 | `existing={名字: 面板}`，平均日截面秩相关。 |

### 基准口径的检查

旧基准与多头端不是同一套成交机制：它是收盘到收盘、按 d−1 日股票池算，看不到停牌期间的涨跌（停牌股当天没有收盘价、被剔除）、看不到退市清零、不扣成本、没有整手和现金拖累。零假设下的超额因此不是 0，而且偏差的符号随区间变——第一版文档说「纯噪声因子的超额是负的（约等于成本拖累）」，在真实数据上不成立，已更正。

合成行情（`Frictions.typical()`：停牌、退市、ST、中途上市；750 天、200 只、零成本，每期重抽的随机分数、前 50%，60 个种子平均）：相对新基准的信息比率 −0.03，相对旧基准 −0.65（测试 `test_random_scores_have_zero_excess_against_default_benchmark`，把默认基准改回旧口径的变异会被它抓到）。

真实数据（`bench/mining/benchmark_check.py`，全市场，前 10%、每 5 天调仓，每只股票一个固定随机分数，15 个；默认账户规模 100 亿元；结果在 `bench/mining/results/benchmark_check.json`）：

| 区间 | 成本 / 账户 | 随机组合对新基准的 IR（均值 ± 标准差） | 随机组合对旧基准的 IR | 「前 100%」对旧基准的 IR（年化超额） | 基准自身的年化成本 |
|---|---|---|---|---|---|
| 2016–2021 | 零 | 0.03 ± 0.54 | 0.44 ± 0.30 | 0.51（+1.47%） | 0 |
| 2016–2021 | A 股默认（默认账户） | 0.02 ± 0.54 | 0.36 ± 0.30 | 0.42（+1.21%） | 0.26% |
| 2016–2021 | A 股默认、1 亿元 | 0.30 ± 0.51 | 0.33 ± 0.30 | 0.18（+0.53%） | 0.63% |
| 2022–2025 | 零 | −0.22 ± 0.37 | −0.23 ± 0.36 | −0.09（−0.04%） | 0 |
| 2022–2025 | A 股默认（默认账户） | −0.22 ± 0.37 | −0.37 ± 0.36 | −0.64（−0.29%） | 0.25% |
| 2022–2025 | A 股默认、1 亿元 | 0.06 ± 0.31 | −0.41 ± 0.36 | −0.71（−0.92%） | 0.71% |

默认设置（默认费用、默认账户）下，对新基准的均值在 15 个样本的标准误（约 0.14、0.10）以内且不为正；对旧基准的偏差 2016–2021 为 +0.4 左右、2022–2025 变号，与复核的结果一致。

**账户规模与最低佣金**：基准持有全部约 5000 只、每 5 天把权重拉回等权，单笔调整很小。账户只有 1 亿元时，最低佣金 5 元让基准每年多扣约 0.4%（上表 0.63–0.71% 对 0.25–0.26%），而前 10% 的组合单笔大、几乎不受影响，零假设下的超额因此偏正（IR 约 +0.3）。所以评估的默认初始资金是 `CAPITAL` = 100 亿元：基准单只约 200 万元，按 5 日涨跌的截面离散度估算，典型的再平衡单笔约十万元，佣金远高于 5 元，最低佣金基本不起作用（合成行情上 1500 只、持有全体时，有无最低佣金的成本相差 0.01%，1 亿元时相差 45%，测试 `test_default_capital_makes_minimum_commission_irrelevant`）。成本模型本身不变。想看自己账户规模下的结果可以传 `capital=`（或自己的 `config=`），但要知道小账户下持有全体的基准会多扣成本、超额偏正，量级如上表。

## 二、表达式搜索（`ashare.factor.mining`）

### 搜索空间

`Space(fields={字段: 量纲}, ops={算子: {参数: 取值}}, max_depth, max_nodes, cs_positions, require_dimensionless, allow_level_ranks)`。量纲 = 价格、成交量两个基本量的指数加一个对数标记；`CATALOG` 里每个算子一条规则：加减、取大取小要求两边量纲相同（价格加成交量在生成时排除），乘除指数相加减，同底对数相减得无量纲，排名、标准化、相关、符号无量纲，滑动均值、最大最小、延迟、差分保持量纲；根节点默认必须无量纲（价格水平、成交量本身不作候选）；截面排名、截面标准分的参数默认也必须无量纲——`cs_rank(close)` 的结果虽然无量纲，量的却是「股价高低、公司大小」，根节点的规则拦不住它，所以单独排除（`allow_level_ranks=True` 放开）。排名套排名、取负套取负、两个相同操作数的二元运算直接排除。默认空间：开高低收、均价、成交量、成交额、换手率 + 四则、取负、绝对值、对数、延迟、差分、滑动均值 / 标准差 / 最大 / 最小 / 排名 / 标准分 / 线性衰减 / 相关、截面排名，深度 3、最多 7 个节点，滑动窗口一律要求满窗口。

### 去重

- **规范形与去重键**：可交换算子（加、乘、取大、取小）的操作数按 `Expr` 摘要排序。去重键在此之上（只用于判重，不改 `expression.py` 的规范形）：`ts_corr` 的两个操作数排序（相关系数对称）；作用在非负量上的 `abs` 去掉（非负字段见 `space.NONNEGATIVE_FIELDS`：价格、成交量、成交额、换手率、市值、复权因子；非负量的滑动均值、最大最小、延迟、和、积、商以及任何量的滑动标准差都非负）；根上的截面排名和截面标准化剥掉（逐日单调，不改变排序和前 N）。去重键相同的只评一次（同一个试验）。取负不剥：只做多时方向不同就是不同的候选。审计见下。
- **数值重复**：过了粗筛的候选在训练段后三分之二里取 16 行，把截面排名居中、缺失记 0、每行归一，存成 float16 指纹；两个指纹逐行内积的平均近似平均日截面秩相关。与已入选（过粗筛且不重复）的候选或 `existing` 里的已有因子相关 ≥ `dedup_threshold`（默认 0.9）的标为重复，不进「发现」，但照样是一次试验。

**去重键审计**（`bench/mining/dedup_audit.py`，`dedup_audit.json`）：默认空间随机生成 20000 次（14875 个不同写法），在 2023 年初到 2024 年年中的全市场真实面板（只读）上求值。

- 键相同、写法不同：新键下有 592 组（旧键 272 组，多出来的是 `ts_corr` 换序和非负量上的 `abs`）。抽 300 对逐日比截面秩相关：最小 0.9999999998，排名不同的格子最多 0.05%（浮点并列）；另有 1 对在这段时间里没有有效值、比不出来。键相同的确实是同一个因子。
- 键不同、排序却完全相同（32 行指纹相关 ≥ 0.9999）：每个键抽一个代表、各 1500 个，新键 3.4%、旧键 4.1%。剩下的没有逐个查明来源，可能是键规则管不到的单调等价（例如对数与滑动最大最小、滑动排名交换次序），它们由过了粗筛以后的数值去重（相关 ≥ 0.9 标为重复、照样计入试验数）兜住，只是多花了粗筛的时间。

### 策略

`Enumerate(limit, batch)` 按深度逐层穷举；`Random(n, seed, batch)` 随机长树（根上偏向算子）；`Evolution(population, generations, tournament, crossover, seed)` 初代随机，之后锦标赛选择 + 交叉（同量纲子树互换）或变异（换参数、换同量纲子树、提升子树），下一代取「上一代 ∪ 后代」最好的 population 个。三者同一接口 `run(space, evaluate)`，可以自己写策略。随机数只来自 `numpy.random.default_rng(seed)`（进化按代 `default_rng([seed, 代号])`），同一空间、同一种子、同一份数据给出同一批候选和同一个结果，与 `panelops`、`panelbt` 的线程数无关（测试在 1 线程和 4 线程下逐位比较）。

### 两段式与适应度

先在训练段算 IC（便宜），训练段 IC 的 t 值 ≥ `screen_t`（默认 1.0）的才跑多头端回测；筛掉的同样记一次试验。台账里已有的候选按**这次**的门槛重判：现在过门槛、台账里有回测结果的直接复用；现在不过的降回粗筛结果（不进折算和挑选，仍是一次试验）；现在过了、台账里只有粗筛结果的补跑回测。所以「先用门槛 0 跑、再用门槛 2 在同一台账上跑」与「门槛 2 在空台账上跑」逐位相同（测试 `test_screen_threshold_is_rejudged_on_reuse`）。适应度默认是训练段多头端超额的信息比率，可换 `"excess_return"`、`"ic"`、`"ic_t"` 或一个只收训练段指标的函数；`complexity` 每个节点扣分。适应度函数拿不到验证段指标。

### 切分与留出（硬规矩）

- `mine(..., split=Split(...))` 的 `split` 没有默认值；`Split.recent(dates, holdout_years=2, valid_years=2)` 给出「最近两年留出、再往前两年验证、其余训练」。
- 搜索只在 `Truncated(panel, 留出段起点)` 上进行：取任何字段都先截掉留出段的行，标签、行情、基准、股票池、`market=` 给的 `BacktestMarket` 都从截断的视图重建，留出段在搜索和挑选的任何代码路径上都读不到。
- 训练段算适应度；验证段只用来挑选（按验证段信息比率排序，取 `select` 个）。段内 IC 只用标签完整落在段内的信号日，训练段的标签不跨进验证段。
- `SearchResult.unlock_holdout(panel)` 在完整面板上只报留出段的指标，一次搜索只能解锁一次（查台账），解锁记一条 `holdout_unlock`。**这是纪律，不是技术上的锁**：换一个台账或数据根目录、删掉台账里的解锁记录，就能再解锁一次。它防的是无意中反复看留出段，防不了有意绕过；台账只负责留下看过的记录。
- 测试：把留出段每个字段换成随机数（含布尔、整数字段），搜索选出的候选、每段指标、适应度、去重判定、入选顺序逐位不变；对照组改动留出段之前的 30 行，结果确实变了。改动验证段及以后的行情，训练段的粗筛结论、指标、适应度逐位不变，验证段的指标确实变了（`test_valid_perturbation_keeps_train_side`）。

### 断点续跑

每个候选评估完立刻追加一行台账（`fsync`）。重启后同一候选（`trial_id` 相同、台账里有粗筛和完整指标）按上面的重判规则直接用记下的指标，记一条 `cache_hit`；过了粗筛的候选的指纹和训练段日超额序列存在 `root/fingerprints/`、`root/series/`，重算去重判定和有效试验数。JSON 浮点往返是精确的，所以续跑结果与一次跑完逐位相同（测试：第 17 条台账后抛异常模拟被杀，重跑后与一次跑完的结果比较）。

## 三、台账

`ashare.ledger.Ledger`（与 `ashare.ml` 共用一个实现，`ashare.ml.ledger` 转出，接口不变；同一 JSONL 格式、`flock`、追加写）。写入中途被杀留下半行时，下一次追加先补一个换行再写，读取时跳过坏行并计数（`skipped_lines`），之后的记录不受影响。一行一个事件：

- `trial`（`kind="factor"`）：`trial_id` = 去重键 + 数据版本 + 评估定义（持有期、调仓、成交错位、成交价 `exec`、分组、前 N、基准口径、股票池与基准收益的摘要、费用与账户的内容摘要、切分行号）的哈希，**不含**搜索策略、适应度和粗筛门槛，所以同一候选在不同搜索里只算一次、可以互相复用；门槛在复用时重判（见上）。换成交价、基准口径或费用就是另一组试验（测试 `test_evaluation_definition_enters_trial_id`）。每条记录同时存粗筛指标（`screen`），供重判用。字段：表达式文本与去重键、搜索编号、空间摘要、策略定义（含种子）、切分、阶段（`screen` / `backtest`）、各段指标、重复判定、代码版本（提交号与工作区是否有改动）、时间；失败的记 `status="failed"` 和异常类型。
- `cache_hit`：续跑或别的搜索遇到已有的候选。
- `holdout_unlock`：解锁留出段。
- 手工研究：`record_trial(ledger, expr, report, data_version=...)` 记成普通的 trial（`source="manual"`）。

`Ledger.trials()` 数不同 `trial_id`：跨多次搜索、跨搜索与手工累计；若与 `ashare.ml` 指到同一个文件，机器学习的试验组也一并累计。

## 四、统计检验（`ashare.factor.stats`）

全部只依赖 NumPy 和标准库，夏普为每期（日）口径。

| 函数 | 定义 | 出处 |
|---|---|---|
| `probabilistic_sharpe` | PSR = Φ[(SR − SR*)·√(T−1) / √(q·(1 − γ3·SR + (γ4−1)/4·SR²))]，q 默认 1 | Bailey & López de Prado (2012) J. of Risk 15(2) 式 (11)；2014 年 DSR 论文式 (2) |
| `expected_max_sharpe` | SR0 = √V·[(1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(Ne))]，γ 为欧拉常数 | Bailey & López de Prado (2014) JPM 40(5) 式 (3) |
| `deflated_sharpe` | DSR = PSR(SR0) | 同上 |
| `adjust` / `reject` | Bonferroni；Holm (1979) 逐步下降 p̃(i) = max_{j≤i} min(1,(m−j+1)p(j))；Benjamini–Hochberg (1995) 逐步上升 p̃(i) = min_{j≥i} min(1, m·p(j)/j)；Benjamini–Yekutieli (2001) 在 BH 上再乘 Σ_{k≤m} 1/k，任意相关下控制 FDR。无效检验（NaN）占分母、不被拒绝 | Holm, Scand. J. Statist. 6(2)；BH, JRSS-B 57(1)；BY, Ann. Statist. 29(4) |
| `pbo_cscv` | 按时间切成 S 块，所有 C(S, S/2) 种训练 / 测试组合，训练集夏普最高者在测试集的相对名次 ω，λ = ln(ω/(1−ω))，PBO = P(λ ≤ 0) | Bailey, Borwein, López de Prado & Zhu (2017) J. Comput. Finance 20(4) 第 2 节 |
| `effective_trials` | 平均相关 M = ρ̄ + (1−ρ̄)N；Nyholt M = 1 + (N−1)(1 − Var(λ)/N)（特征值方差按 N−1 归一）；Li–Ji M = Σ[1(|λ|≥1) + |λ| − ⌊|λ|⌋] | Bailey & López de Prado (2014) 第 3 节、López de Prado (2018) 第 14 章；Nyholt (2004) AJHG 74(4)；Li & Ji (2005) Heredity 95(3) |
| `variance_ratio` | q = 1 + 2·Σ_{j≤L}(1 − j/(L+1))·ρ_j（Bartlett 权重的长期方差 ÷ 普通方差），默认不低于 1 | Lo (2002) FAJ 58(4)「The Statistics of Sharpe Ratios」；Newey & West (1987) |
| `overlap_t` | 重叠持有期日 IC 的保守 t：均值 / √(s²·h/n)，自由度 ⌊n/h⌋ − 1 | 见下 |
| `hac_t` | 均值的 HAC t 值：Bartlett 核（Newey & West 1987）或均匀核（Hansen & Hodrick 1980）；不再用于 IC 的 p 值 | Econometrica 55(3)；JPE 88(5) |
| `student_sf`、`p_from_t` | Student t 上尾，用正则化不完全贝塔函数的连分式（Numerical Recipes 6.4 节） | — |

**IC 的 t 值为什么这样算**：持有 h 天的收益在相邻信号日之间重叠 h − 1 天，零假设下日 IC 的 j 阶自相关不超过 (h − j)/h（重叠比例乘以因子自身的自相关，后者绝对值不超过 1），所以均值的方差不超过 γ0·h/n。第一版用均匀核 HAC 估这个方差，样本短、h 大时估计偏小（复核测得 h = 20、n = 250 时 Holm 的族错误率 0.169），自由度 n/h − 1 的 t 分布补不回来。现在分母直接取上界 s²·h/n，自由度按不重叠的块数算；h = 1 就是普通单样本 t 检验。代价是功效：因子自相关衰减得快时，真实方差远小于上界，t 值最多被压低 √h 倍（模拟里 AR(1) φ = 0.9 的因子、h = 20 时 Holm 一次都不拒绝）。不重叠的块少于 10 个（例如 h = 20 而训练段不到 200 天）时不给 p 值，报告里写明原因，这些候选不参与 IC 的多重检验（按无效检验占分母）。

与 `ashare.ml.metrics.ic_stats` 的差别：那边按 √(n/h) 折算 t 值、用正态 p 值，没有改（按负责人的决定，ml 的接口和输出不动）；同一个因子在两处的显著性可能不同，判断「发现」以这里（`ashare.factor.stats.overlap_t` / `ic_summary`）为准。

**夏普的序列相关修正**：PSR、DSR 原文假定日超额独立同分布。带风格暴露的多头端超额常有正自相关（复核在真实数据上测得市值类候选 q 约 1.4–2.0），标准误被低估，z 值偏大到 √q 倍。现在按 Lo (2002) 的思路把夏普估计量的方差乘以 q（`sharpe_variance(..., q=)`、`probabilistic_sharpe(..., q=)`、`deflated_sharpe(..., q=)`），搜索里每个候选用自己训练段超额的 q（Bartlett 核 10 阶，不低于 1——负自相关不拿来放松检验），零假设方差相应取 q/(T−1)。默认打开，`mine(..., autocorr=False)` 关掉；报告里每个候选给出 `q_train`，单因子评估给出 `long.var_ratio`。

**有效试验数的局限**：只看线性相关、假定相关结构平稳；候选少、样本短时特征值噪声大（Li–Ji 在两组完全相关的簇上会给出 3 而不是 2），只作量级参考。折算时默认仍用原始试验数（更保守）。

**对拍**：2014 年论文的数值例子（年化夏普 2.5、T = 1250、偏度 −3、峰度 10、N = 100、V = 0.5/250 → SR0 ≈ 0.1132、DSR ≈ 0.9004）；PSR 手算；期望最大夏普对 4000 次模拟的最大值（N = 10、100、1000，误差 < 5%）；Holm、BH、BY 手算例子，Holm、BH 与逐项循环的参考实现（随机 37 个 p 值）；完全零假设下 2000 次模拟的族错误率；PBO 对逐元素循环的参考实现，及「一个候选每段都更好 → PBO = 0」；有效试验数的三种公式手算（4 × 4、ρ = 0.5）；HAC 对逐项求和的参考；Student t 对 df = 1、2 的闭式解；重叠和的均值在零假设下的拒绝率（均匀核不超名义水平太多、Bartlett 明显偏高）；`overlap_t` 对手算公式、h = 1 时对 SciPy 的单样本 t 检验；h = 20、n = 250 的重叠 IC 上 Holm 的族错误率不超名义水平；方差比对逐项求和的参考和 AR(1) 的理论值 (1+φ)/(1−φ)；带 q 的 PSR、DSR 对手算。

### 搜索报告里的折算

- **IC**：本次搜索每个候选的训练段 IC p 值，补 NaN 到台账累计试验数（之前的试验同样占分母），做 Holm、BH、BY，报拒绝个数；另报未校正的个数作对照。
- **多头端**：每个不重复的回测候选算训练段超额的 PSR（门槛 0、不折算）和 DSR（N = 台账累计试验数），都按该候选的 q 修正。DSR 的 V 默认取零假设下单个夏普估计量的方差 q/(T−1)（`sr_var="null"`）；`"empirical"` 是原文的「各试验夏普的截面方差」（观测到的离散度，不再乘 q），`"max"` 取两者大者。结果里 `dsr_train` 按所选的算，`dsr_train_null` 总按零假设。
- **验证段**：在不重复的回测候选里按验证段信息比率挑选，验证段 DSR 的 N = 参与挑选的个数。「训练段与验证段都过」才算通过。
- 另报：本次回测候选的有效试验数（Li–Ji，训练段日超额）、PBO（CSCV，10 块）、与已有因子的相关。PBO 只在训练段、只在过了粗筛且不重复的回测候选上做；没有候选进入回测、不重复的候选不足 2 个、或共同有效的天数不足 40 时显示「不适用」并写明原因（`pbo_note`），不再报一个 0 让人误读。

两种 V 各偏向哪边：零假设方差 q/(T−1) 是全局零假设下单个夏普的抽样方差，而 SR0 取的是 N 个里的期望最大值，所以在全局零假设下偏保守（噪声模拟与真实收益噪声上都没有误报）；会让它偏松的是零假设下超额不为 0（已由同口径基准修正；小账户下最低佣金另有偏差，默认账户规模已消除，见第一节）和序列相关（已由 q 修正）。试验彼此高度相关、厚尾、成本让夏普整体为负，都让它更保守。经验方差在候选里有真信号时被撑大，偏保守得多，基本找不回信号；候选全是噪声时比零假设方差还小（真实收益噪声上二者之比 0.50–0.89），门槛反而更低（1 亿元账户时固定分数那一行出过一次误报）。

为什么默认不用原文的经验方差：V 是「零假设下各试验夏普估计值的离散程度」。候选池里有真信号时，经验方差被真信号之间的差异撑大，门槛随之抬高——下面的埋信号模拟里，按经验方差折算后一次也没有找回埋入的信号，而按零假设方差在强信号下 8 成能找回；两种在纯噪声上都没有误报。零假设方差在 SR = 0 处与偏度、峰度无关，所以对厚尾收益仍然成立；候选彼此相关时用原始 N 偏保守。

| 随机 | 1000 | 772 | 228 | 51 | 0 | 1000 | 204 / 113 / 171 / 151 | 0 / 0 / 0 | 约 78 | 0.00 | 64（15.7 个/秒） |
| 进化 | 600 | 277 | 323 | 154 | 125 | 1475 | 309 / 243 / 295 / 277 | 10 / 0 / 0 | 约 57 | 0.00 | 50（9.5 个/秒） |

训练段折算夏普：随机的 177 个不重复回测候选全部在 [0, 0.5)；进化的 169 个里 167 个在 [0, 0.5)、2 个在 [0.5, 0.9)。验证段两次全部在 [0, 0.5)。进化把未折算的 PSR 推到了 10 个过 0.95（适应度就是训练段的超额信息比率，进化本来就是在挑训练段好看的）。PBO 接近 0 的读法：它只在训练段、只在过了粗筛的候选之间比较「训练段最好的那个在另一半时间里排第几」，这些候选彼此高度相关（有效试验数只有几十），训练段排前面的在另一半里也排前面，所以 PBO 低；它不说明候选的超额显著，显著性看折算夏普。

结论如实写：训练段的 Rank IC 用了更保守的 t 值，Holm 校正后仍有上百个显著（量价因子在 A 股的截面预测力本身不弱）；换成多头端、扣掉成本、相对同口径的等权基准算超额以后，未折算的 PSR 过 0.95 的随机 0 个、进化 10 个，**按试验数折算之后一个都不剩**，验证段也没有一个同时通过。没有为了好看调参数（门槛、成本、调仓频率都是默认值）。

## 七、性能基线

`bench/mining/perf.py`，全市场（2430 个交易日 × 5923 只）、10 年、默认空间随机 100 个表达式，三次取中位数。

这一轮（基准改为同口径、IC t 值改口径、默认账户改为 100 亿元之后）重测。负载：开始时 1/5/15 分钟平均负载 12.05 15.10 13.21，结束时 14.73 15.27 13.45（15 核，同时有别的会话在跑）。三次总耗时 17.9、18.8、19.2 秒。

| 步骤（100 个因子，三次中位数） | 秒 |
|---|---|
| 读字段（内存映射首次读入，一次） | 0.21 |
| 准备：标签（四个持有期）、股票池、行情、市值段 | 0.45 |
| 默认基准（同口径「前 100%」组合跑一遍回测，一次） | 0.18 |
| 表达式求值（`Evaluator.evaluate_many`，按内存上限分 2 批） | 2.46 |
| IC（3 个持有期）、分组、市值段、自相关、选股 | 15.05 |
| 多头端回测（一次 `run_batch`，100 个策略） | 0.27 |
| 汇总（分段、分年度） | 0.08 |
| **合计** | **18.8** |
| 只做粗筛（表达式求值 + 筛选持有期 IC） | 5.09 |

便宜部分的分步（毫秒 / 因子，10 个因子平均）：ic_h1 15.3、ic_h5 14.9、ic_h20 14.9、groups 14.4、size_ic 20.3、autocorr 64.4、targets 6.5。新基准只多一次回测（约 0.2 秒），账户规模不影响耗时；上一轮合计 17.8 秒（负载约 10），这一轮负载约 15，各步按比例变慢，差别在负载波动之内。

对照基线：

- Rank IC（一个因子、一个持有期）：NumPy 逐日 argsort 的直白写法 1.38 秒，`panelops`（收益排序预先做好、按行并行）16.4 毫秒，约 84 倍。照直白写法，100 个因子 × 7 次秩相关就要十几分钟。
- 回测 10 个策略：逐个 `panelbt.run` 0.31 秒，一次 `run_batch` 0.032 秒。

结论与已经做的下沉：收益的逐日排序对每个持有期、每个市值段只做一次（`_RankIC` 复用 `panelops.rank_ic_many` 的有序内核，逐位相同；市值段 IC 由 21.6 降到 15.3 毫秒 / 因子）；搜索的两段式只对过了粗筛的候选算分组、市值段、自相关和回测，粗筛一个候选约 45 毫秒（含表达式求值）。剩下最大的一块是因子自相关（两个滞后约 49 毫秒，每次都把两天的截面重新排序），值得写一个「一次排序、多个滞后」的 Rust 内核，留给 `panelops` 那条线；回测已经不是瓶颈。

## 八、已知局限

- **幸存者**：股票池按当时的上市状态取，退市股在退市前照常在池内；退市后没有价格的标签缺失（不计入 IC）。多头端由 `panelbt` 按退市规则处理。
- **容量**：等权前 10%，没有成交量约束（`Config.max_participation` 默认 0）；小市值、低流动性的票照常买满。容量与冲击成本见 `ashare.analysis`。
- **成本**：A 股历史印花税、过户费 + 佣金万 2.5（最低 5 元）+ 滑点 5 bp；没有冲击成本。基准与多头端同一套成本；默认账户 100 亿元，让最低佣金不起作用，这个规模下仍然没有容量和冲击的约束（见「容量」一条）；传小账户时基准会多扣成本、超额偏正（第一节）。
- **多头端口径**：只做多、相对同口径的股票池等权基准；不代表能做空的多空收益。卖出日跌停卖不出时 IC 标签仍按当日价（偏乐观），多头端回测则由引擎顺延。
- **IC 的 p 值偏保守**：分母取重叠方差的上界，衰减快的因子 t 值被压低（第四节）；粗筛门槛用的也是这个 t 值，所以这类因子更难进入回测。
- **两段式**：只有过了粗筛的候选有多头端指标；DSR 的试验数用全部试验（含筛掉的），经验方差只能用回测过的候选估计。
- **折算的保守程度**：候选彼此高度相关，原始试验数远大于有效试验数，DSR 偏保守；有效试验数只作参考。q 只修正到 10 阶的序列相关，更长的慢变量（如跨月的风格周期）修正不到。
- **留出段解锁**：只能解锁一次是纪律，不是技术锁（第二节）。
- **指纹去重**：只看训练段 16 天、缺失按中位数处理，是平均截面秩相关的近似。
