# 因子挖掘：评估、搜索、台账与多重检验

设计见 `docs/DESIGN.md` 6.2.2。本仓库只放机制；挖出来的因子、试验记录、台账文件一律不进仓库（默认写到数据根目录下不入库的 `mining/`，`ASHARE_MINING_DIR` 或 `root=` 可指到私有仓库）。本文的例子和测试只用自编的玩具表达式和量价基础字段。

## 最短例子

```python
from ashare.factor.mining import Random, Split, mine
from ashare.factor.mining.synthetic import market

panel = market(t=900, n=150, strength=0.003)     # 合成行情，埋了一个已知信号
split = Split.recent(panel.dates, holdout_years=1, valid_years=1)
result = mine(panel, split=split, strategy=Random(n=60, seed=1), root="/tmp/mining-demo")
print(result.text())                              # 试了多少、去重、折算后剩多少
holdout = result.unlock_holdout(panel)            # 只能解锁一次，解锁记进台账
```

单个因子：

```python
from ashare.factor import Evaluator, evaluate_factor
report = evaluate_factor(Evaluator().evaluate(expr, panel), panel)
print(report.text())                              # report.to_dict() 只有基本类型
```

真实数据上 `panel = ashare.data.open().panel(FactorEvaluator.required_fields() + 字段)`，多头端用 `market=ashare.backtest.market_from_panel(data, panel=panel)`（按板块的整手规则）。

## 一、单因子评估（`ashare.factor.evaluate`）

`FactorEvaluator(panel, ...)` 准备一次（标签、股票池、行情、基准、市值段），`evaluate_many({名字: 面板})` 评估一批。

| 内容 | 口径 |
|---|---|
| 收益标签 | 直接调 `ashare.ml.labels.compute`：信号日 t 收盘后出信号，t+1 开盘买、t+1+h 开盘卖，价格乘复权因子；买入日不可买（停牌、涨停、一字板，口径同 `market_from_panel`）的样本不进 IC；卖出日不可卖按当日价（`sell_blocked="price"`，偏乐观）。退市后没有价格的样本缺失。 |
| 股票池 | 默认 `ashare.ml.default_universe`：已上市、非 ST、上市满 120 日、当天有行情。股票池外的因子值置缺失。 |
| Rank IC | 每个持有期（默认 1、5、20）的日截面 Spearman（`panelops`，收益排序只做一次）。均值、标准差、ICIR（日频不年化）；t 值的标准误用 Hansen–Hodrick 均匀核 HAC、滞后 h − 1；p 值单侧，按自由度 n/h − 1 的 Student t。段内只用标签完整落在段内的信号日（t + 1 + h < 段尾）。 |
| 分组 | `panelops.group_returns`（序数分组，默认 10 组）在筛选持有期上的平均收益；单调性 = 组号与组均值名次的相关；最高减最低。 |
| 多头端 | 最高组（默认前 10%，`top=N` 改为前 N 只）等权，每 `rebalance`（默认 5）个交易日在信号日选股，`ashare.backtest.execution_targets` 错到下一行成交，`panelbt.run_batch` 一次跑一批（A 股历史印花税、过户费、佣金万 2.5 最低 5 元、滑点 5 bp，初始资金 1 亿）。相对基准（默认股票池等权的收盘到收盘收益，d−1 日在池内的股票；可传任意长度 T 的日收益）：年化（几何）、基准年化、超额（日超额均值 × 252）、信息比率、夏普、最大回撤、年化换手、年化成本占净值比例，以及超额日序列的每期夏普、偏度、峰度（折算夏普用）。 |
| 分年度、分市值段 | 每个日历年的 IC 与超额；按总市值把股票池三等分的 IC。 |
| 自相关 | `panelops.factor_autocorr`，滞后 1 和调仓间隔。 |
| 与已有因子的相关 | `existing={名字: 面板}`，平均日截面秩相关。 |

基准默认不扣成本，多头端扣成本，所以纯噪声因子的超额是负的（约等于成本拖累）；需要看「毛超额」时传零成本的 `costs`。

## 二、表达式搜索（`ashare.factor.mining`）

### 搜索空间

`Space(fields={字段: 量纲}, ops={算子: {参数: 取值}}, max_depth, max_nodes, cs_positions, require_dimensionless)`。量纲 = 价格、成交量两个基本量的指数加一个对数标记；`CATALOG` 里每个算子一条规则：加减、取大取小要求两边量纲相同（价格加成交量在生成时排除），乘除指数相加减，同底对数相减得无量纲，排名、标准化、相关、符号无量纲，滑动均值、最大最小、延迟、差分保持量纲；根节点默认必须无量纲（价格水平、成交量本身不作候选）。排名套排名、取负套取负、两个相同操作数的二元运算直接排除。默认空间：开高低收、均价、成交量、成交额、换手率 + 四则、取负、绝对值、对数、延迟、差分、滑动均值 / 标准差 / 最大 / 最小 / 排名 / 标准分 / 线性衰减 / 相关、截面排名，深度 3、最多 7 个节点，滑动窗口一律要求满窗口。

### 去重

- **规范形**：可交换算子（加、乘、取大、取小）的操作数按 `Expr` 摘要排序；去重键再剥掉根上的截面排名和截面标准化（逐日单调，不改变排序和前 N）。去重键相同的只评一次（同一个试验）。取负不剥：只做多时方向不同就是不同的候选。
- **数值重复**：过了粗筛的候选在训练段后三分之二里取 16 行，把截面排名居中、缺失记 0、每行归一，存成 float16 指纹；两个指纹逐行内积的平均近似平均日截面秩相关。与已入选（过粗筛且不重复）的候选或 `existing` 里的已有因子相关 ≥ `dedup_threshold`（默认 0.9）的标为重复，不进「发现」，但照样是一次试验。

### 策略

`Enumerate(limit, batch)` 按深度逐层穷举；`Random(n, seed, batch)` 随机长树（根上偏向算子）；`Evolution(population, generations, tournament, crossover, seed)` 初代随机，之后锦标赛选择 + 交叉（同量纲子树互换）或变异（换参数、换同量纲子树、提升子树），下一代取「上一代 ∪ 后代」最好的 population 个。三者同一接口 `run(space, evaluate)`，可以自己写策略。随机数只来自 `numpy.random.default_rng(seed)`（进化按代 `default_rng([seed, 代号])`），同一空间、同一种子、同一份数据给出同一批候选和同一个结果，与 `panelops`、`panelbt` 的线程数无关（测试在 1 线程和 4 线程下逐位比较）。

### 两段式与适应度

先在训练段算 IC（便宜），训练段 IC 的 t 值 ≥ `screen_t`（默认 1.0）的才跑多头端回测；筛掉的同样记一次试验。适应度默认是训练段多头端超额的信息比率，可换 `"excess_return"`、`"ic"`、`"ic_t"` 或一个只收训练段指标的函数；`complexity` 每个节点扣分。适应度函数拿不到验证段指标。

### 切分与留出（硬规矩）

- `mine(..., split=Split(...))` 的 `split` 没有默认值；`Split.recent(dates, holdout_years=2, valid_years=2)` 给出「最近两年留出、再往前两年验证、其余训练」。
- 搜索只在 `Truncated(panel, 留出段起点)` 上进行：取任何字段都先截掉留出段的行，标签、行情、基准、股票池、`market=` 给的 `BacktestMarket` 都从截断的视图重建，留出段在搜索和挑选的任何代码路径上都读不到。
- 训练段算适应度；验证段只用来挑选（按验证段信息比率排序，取 `select` 个）。段内 IC 只用标签完整落在段内的信号日，训练段的标签不跨进验证段。
- `SearchResult.unlock_holdout(panel)` 在完整面板上只报留出段的指标，一次搜索只能解锁一次（查台账），解锁记一条 `holdout_unlock`。
- 测试：把留出段每个字段换成随机数（含布尔、整数字段），搜索选出的候选、每段指标、适应度、去重判定、入选顺序逐位不变；对照组改动留出段之前的 30 行，结果确实变了。

### 断点续跑

每个候选评估完立刻追加一行台账（`fsync`）。重启后同一候选（`trial_id` 相同、台账里有完整指标）直接用记下的指标，记一条 `cache_hit`；过了粗筛的候选的指纹和训练段日超额序列存在 `root/fingerprints/`、`root/series/`，重算去重判定和有效试验数。JSON 浮点往返是精确的，所以续跑结果与一次跑完逐位相同（测试：第 17 条台账后抛异常模拟被杀，重跑后与一次跑完的结果比较）。

## 三、台账

直接用 `ashare.ml.ledger.Ledger`（同一 JSONL 格式、`flock`、追加写、半行跳过）。一行一个事件：

- `trial`（`kind="factor"`）：`trial_id` = 去重键 + 数据版本 + 评估定义（持有期、调仓、分组、前 N、股票池与基准的摘要、费用与账户的内容摘要、切分行号）的哈希，**不含**搜索策略与适应度，所以同一候选在不同搜索里只算一次、可以互相复用。字段：表达式文本与去重键、搜索编号、空间摘要、策略定义（含种子）、切分、阶段（`screen` / `backtest`）、各段指标、重复判定、代码版本（提交号与工作区是否有改动）、时间；失败的记 `status="failed"` 和异常类型。
- `cache_hit`：续跑或别的搜索遇到已有的候选。
- `holdout_unlock`：解锁留出段。
- 手工研究：`record_trial(ledger, expr, report, data_version=...)` 记成普通的 trial（`source="manual"`）。

`Ledger.trials()` 数不同 `trial_id`：跨多次搜索、跨搜索与手工累计；若与 `ashare.ml` 指到同一个文件，机器学习的试验组也一并累计。

## 四、统计检验（`ashare.factor.stats`）

全部只依赖 NumPy 和标准库，夏普为每期（日）口径。

| 函数 | 定义 | 出处 |
|---|---|---|
| `probabilistic_sharpe` | PSR = Φ[(SR − SR*)·√(T−1) / √(1 − γ3·SR + (γ4−1)/4·SR²)] | Bailey & López de Prado (2012) J. of Risk 15(2) 式 (11)；2014 年 DSR 论文式 (2) |
| `expected_max_sharpe` | SR0 = √V·[(1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(Ne))]，γ 为欧拉常数 | Bailey & López de Prado (2014) JPM 40(5) 式 (3) |
| `deflated_sharpe` | DSR = PSR(SR0) | 同上 |
| `adjust` / `reject` | Bonferroni；Holm (1979) 逐步下降 p̃(i) = max_{j≤i} min(1,(m−j+1)p(j))；Benjamini–Hochberg (1995) 逐步上升 p̃(i) = min_{j≥i} min(1, m·p(j)/j)；Benjamini–Yekutieli (2001) 在 BH 上再乘 Σ_{k≤m} 1/k，任意相关下控制 FDR。无效检验（NaN）占分母、不被拒绝 | Holm, Scand. J. Statist. 6(2)；BH, JRSS-B 57(1)；BY, Ann. Statist. 29(4) |
| `pbo_cscv` | 按时间切成 S 块，所有 C(S, S/2) 种训练 / 测试组合，训练集夏普最高者在测试集的相对名次 ω，λ = ln(ω/(1−ω))，PBO = P(λ ≤ 0) | Bailey, Borwein, López de Prado & Zhu (2017) J. Comput. Finance 20(4) 第 2 节 |
| `effective_trials` | 平均相关 M = ρ̄ + (1−ρ̄)N；Nyholt M = 1 + (N−1)(1 − Var(λ)/N)（特征值方差按 N−1 归一）；Li–Ji M = Σ[1(|λ|≥1) + |λ| − ⌊|λ|⌋] | Bailey & López de Prado (2014) 第 3 节、López de Prado (2018) 第 14 章；Nyholt (2004) AJHG 74(4)；Li & Ji (2005) Heredity 95(3) |
| `hac_t` | 均值的 HAC t 值：Bartlett 核（Newey & West 1987）或均匀核（Hansen & Hodrick 1980） | Econometrica 55(3)；JPE 88(5) |
| `student_sf`、`p_from_t` | Student t 上尾，用正则化不完全贝塔函数的连分式（Numerical Recipes 6.4 节） | — |

**有效试验数的局限**：只看线性相关、假定相关结构平稳；候选少、样本短时特征值噪声大（Li–Ji 在两组完全相关的簇上会给出 3 而不是 2），只作量级参考。折算时默认仍用原始试验数（更保守）。

**对拍**：2014 年论文的数值例子（年化夏普 2.5、T = 1250、偏度 −3、峰度 10、N = 100、V = 0.5/250 → SR0 ≈ 0.1132、DSR ≈ 0.9004）；PSR 手算；期望最大夏普对 4000 次模拟的最大值（N = 10、100、1000，误差 < 5%）；Holm、BH、BY 手算例子，Holm、BH 与逐项循环的参考实现（随机 37 个 p 值）；完全零假设下 2000 次模拟的族错误率；PBO 对逐元素循环的参考实现，及「一个候选每段都更好 → PBO = 0」；有效试验数的三种公式手算（4 × 4、ρ = 0.5）；HAC 对逐项求和的参考；Student t 对 df = 1、2 的闭式解；重叠和的均值在零假设下的拒绝率（均匀核不超名义水平太多、Bartlett 明显偏高）。

### 搜索报告里的折算

- **IC**：本次搜索每个候选的训练段 IC p 值，补 NaN 到台账累计试验数（之前的试验同样占分母），做 Holm、BH、BY，报拒绝个数；另报未校正的个数作对照。
- **多头端**：每个不重复的回测候选算训练段超额的 PSR（门槛 0、不折算）和 DSR（N = 台账累计试验数）。DSR 的 V 默认取零假设下单个夏普估计量的方差 1/(T−1)（`sr_var="null"`）；`"empirical"` 是原文的「各试验夏普的截面方差」，`"max"` 取两者大者。结果里 `dsr_train` 按所选的算，`dsr_train_null` 总按零假设。
- **验证段**：在不重复的回测候选里按验证段信息比率挑选，验证段 DSR 的 N = 参与挑选的个数。「训练段与验证段都过」才算通过。
- 另报：本次回测候选的有效试验数（Li–Ji，训练段日超额）、PBO（CSCV，10 块）、与已有因子的相关。

为什么默认不用原文的经验方差：V 是「零假设下各试验夏普估计值的离散程度」。候选池里有真信号时，经验方差被真信号之间的差异撑大，门槛随之抬高——下面的埋信号模拟里，按经验方差折算后一次也没有找回埋入的信号，而按零假设方差在强信号下 8 成能找回；两种在纯噪声上都没有误报。零假设方差在 SR = 0 处与偏度、峰度无关，所以对厚尾收益仍然成立；候选彼此相关时用原始 N 偏保守。

## 五、模拟检验

`bench/mining/simulate.py`，合成行情（`ashare.factor.mining.synthetic.market`）：价格分隔夜、日内两段独立随机游走，t+1 开盘以后的收益与 t 日及以前的一切独立。T = 760 个交易日、120 只股票，最后一年留出、之前一年验证、其余（约一年）训练；α = 0.05。

**纯噪声**：每次重复换一份行情、在默认空间上随机采样 80 个候选跑完整搜索，数「这次搜索有没有至少一个候选被判显著」（族错误率）。

| 判定（每次搜索至少一个算显著的比例） | A 股默认费用 | 零成本 |
|---|---|---|
| 训练段 IC 未校正（任一 p ≤ 0.05） | 186/200（0.930） | 187/200（0.935） |
| 训练段 IC，Holm（N = 台账累计） | 10/200（0.050） | 11/200（0.055） |
| 训练段 IC，BH | 16/200（0.080） | 13/200（0.065） |
| 训练段 IC，BY | 4/200（0.020） | 5/200（0.025） |
| 多头端 PSR > 0.95（不折算） | 32/200（0.160） | 135/200（0.675） |
| 多头端折算夏普 > 0.95（V 取零假设，默认） | 0/200（0.000） | 0/200（0.000） |
| 多头端折算夏普 > 0.95（V 取经验方差） | 0/200（0.000） | 0/200（0.000） |
| 训练段与验证段折算夏普都过 | 0/200（0.000） | 0/200（0.000） |

每次 80 个候选，共 200 次重复（种子不同）；名义水平 0.05，200 次时 3 倍标准差的上限为 0.096。单个候选未校正的 IC 拒绝率 0.052 / 0.056（名义 0.05）。

读法：

- 折算后的多头端判定（本线真正用来宣布「发现」的）400 次里一次都没有误报；不折算的 PSR 在零成本时 68% 的搜索里至少挑出一个「显著」的，这正是要折算的原因。
- IC 的 Holm 两种成本合计 21/400（0.052），在名义水平的抽样误差之内；BY 更低。BH 合计 0.072，**略高于 0.05**（在 3 倍标准差之内）：完全零假设下 BH 的错误发现率等于族错误率，只在检验统计量正相关（PRDS）时有保证，而候选里同时有 x 与 −x 这类负相关的单侧检验。要严格控制时看 Holm 或 BY（`stats.adjust(..., "by")`），报告里三种都给。
- 多头端在默认费用下纯噪声的超额是负的（成本拖累），所以默认费用那一列天然偏保守；零成本那一列才是零假设精确成立的检验。

**埋信号**：把「过去 5 日收益的相反数」的截面标准分乘以强度加到下一日的日内收益上（`negate(close / ts_delay(close, periods=5))` 在 t 日收盘可知、预测 t+1 开盘到 t+2 开盘的收益），在一个含它的小空间（收盘、开盘、成交量；除、取负、延迟 1/5、均值 5/20；深度 3、最多 5 个节点，穷举 662 个）上搜索。「找回」= 埋入的信号或数值上等价的写法（指纹相关 > 0.95）被回测，且训练段 DSR（N = 全部试验数）> 0.95。

| 强度（每标准差的日收益） | 被回测 | 训练段折算夏普找回（V 取零假设，默认） | 同上（V 取经验方差） | 训练段 IC 的 Holm 至少一个显著 | 验证段第一名与它相关 > 0.6 |
|---|---|---|---|---|---|
| 0.001 | 10/10 | 0/10 | 0/10 | 10/10 | 7/10 |
| 0.002 | 10/10 | 3/10 | 0/10 | 10/10 | 8/10 |
| 0.003 | 10/10 | 8/10 | 0/10 | 10/10 | 8/10 |

强度 0.003 时，单次例子里埋入信号的验证段多头端信息比率约为 5（合成行情）。空间里与它高度相关的写法很多（例如收盘价相对 5 日均价），验证段第一名多数是这一族里的某一个。按原文的经验方差折算时一次也找不回来：候选池里一族真信号的夏普彼此差异很大，经验方差被撑大、门槛随之抬高，这是默认改用零假设方差的依据。弱信号（0.001）在 IC 上全部能被 Holm 检出，但扣成本后的多头端不够强，折算后找不回——多头端口径本来就比 IC 严。

**一处修正**：第一版 IC 的 p 值用正态近似。纯噪声模拟里 Holm 的族错误率为 0.10–0.13、BH 为 0.13–0.17（100 次，3 倍标准差上限 0.115）。原因是训练段只有约 250 个交易日、h = 5 时不重叠的样本只有约 50 个，HAC 方差在小样本里偏小，Holm 的门槛（m = 80 时 z ≈ 3.2）落在正态尾部太薄的地方。改为自由度 n/h − 1 的 Student t 后，同样那 100 个种子（零成本）上 Holm 0.03、BH 0.04。另外第一版用 Bartlett 核：持有 5 天时它把 MA(4) 的自协方差打了折，长期方差只算到真值的约 0.68，t 值偏大约 1.2 倍，改为均匀核。

## 七、性能基线

`bench/mining/perf.py`，全市场（2430 个交易日 × 5923 只）、10 年、默认空间随机 100 个表达式，三次取中位数。

负载：开始时 1/5/15 分钟平均负载 9.37 10.86 9.58，结束时 16.06 12.75 10.42（15 核，同时有十来个代理在编译和跑测试）。三次总耗时 16.6, 17.8, 18.8 秒。

| 步骤（100 个因子，三次中位数） | 秒 |
|---|---|
| 读字段（内存映射首次读入，一次） | 0.18 |
| 准备：标签（四个持有期）、股票池、行情、基准、市值段 | 0.35 |
| 表达式求值（`Evaluator.evaluate_many`，按内存上限分 2 批） | 2.23 |
| IC（3 个持有期）、分组、市值段、自相关、选股 | 14.84 |
| 多头端回测（一次 `run_batch`，100 个策略） | 0.24 |
| 汇总（分段、分年度） | 0.08 |
| **合计** | **17.8** |
| 只做粗筛（表达式求值 + 筛选持有期 IC） | 4.48 |

便宜部分的分步（毫秒 / 因子，10 个因子平均）：ic_h1 11.7、ic_h5 11.7、ic_h20 11.5、groups 12.8、size_ic 15.3、autocorr 48.7、targets 4.5。

对照基线：

- Rank IC（一个因子、一个持有期）：NumPy 逐日 argsort 的直白写法 1.18 秒，`panelops`（收益排序预先做好、按行并行）10.2 毫秒，约 116 倍。照直白写法，100 个因子 × 7 次秩相关就要十几分钟。
- 回测 10 个策略：逐个 `panelbt.run` 0.23 秒，一次 `run_batch` 0.031 秒。

结论与已经做的下沉：收益的逐日排序对每个持有期、每个市值段只做一次（`_RankIC` 复用 `panelops.rank_ic_many` 的有序内核，逐位相同；市值段 IC 由 21.6 降到 15.3 毫秒 / 因子）；搜索的两段式只对过了粗筛的候选算分组、市值段、自相关和回测，粗筛一个候选约 45 毫秒（含表达式求值）。剩下最大的一块是因子自相关（两个滞后约 49 毫秒，每次都把两天的截面重新排序），值得写一个「一次排序、多个滞后」的 Rust 内核，留给 `panelops` 那条线；回测已经不是瓶颈。

## 八、已知局限

- **幸存者**：股票池按当时的上市状态取，退市股在退市前照常在池内；退市后没有价格的标签缺失（不计入 IC）。多头端由 `panelbt` 按退市规则处理。
- **容量**：等权前 10%，没有成交量约束（`Config.max_participation` 默认 0）；小市值、低流动性的票照常买满。容量与冲击成本见 `ashare.analysis`。
- **成本**：A 股历史印花税、过户费 + 佣金万 2.5（最低 5 元）+ 滑点 5 bp；没有冲击成本。基准不扣成本。
- **多头端口径**：只做多、相对等权基准；不代表能做空的多空收益。卖出日跌停卖不出时 IC 标签仍按当日价（偏乐观），多头端回测则由引擎顺延。
- **标签依赖 `ashare.ml`**：评估要装可选依赖组 `ml`（`make dev` 默认装）；`ashare.factor.stats` 不依赖它。
- **两段式**：只有过了粗筛的候选有多头端指标；DSR 的试验数用全部试验（含筛掉的），经验方差只能用回测过的候选估计。
- **折算的保守程度**：候选彼此高度相关，原始试验数远大于有效试验数，DSR 偏保守；有效试验数只作参考。纯噪声下多头端扣成本后超额为负，那一列检验天然偏保守，所以模拟另跑了零成本。
- **指纹去重**：只看训练段 16 天、缺失按中位数处理，是平均截面秩相关的近似。
