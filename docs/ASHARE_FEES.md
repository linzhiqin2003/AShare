### 为什么 2015 年以前同时计按股和按金额两种

`panelbt.Costs` 的税费只能随日期变化，不能随证券变化。2015-08-01 以前沪深两市的过户费口径不同（沪市按面值即按股数，深市按金额），表里两种同时计入，对每只股票都是上限：沪市股票多算了深市那一份，深市股票多算了沪市那一份。按股 0.001 元在 10 元的股票上约是成交金额的 0.01%。

同理，2021-11-15 到 2022-04-28 用了北交所较高的 0.025‰。

2012-06-01 沪市曾先降到面值的 0.375‰，到 8 月底之间投资者实际按多少缴没有查到，表里继续用更高的 0.001 元 / 股，到 2012-09-01 才降。

## 用法

```python
from panelbt.markets import ASHARE

ASHARE.costs(dates, commission_rate=2.5e-4)          # 全历史，按表
ASHARE.costs(dates, tax_buy=0, tax_sell=0.001,        # 全区间固定费率：四个分量都覆盖
             fee_rate_buy=1e-5, fee_rate_sell=1e-5)
```

覆盖某个方向的过户费（`fee_rate_buy` 或 `fee_per_share_buy`，卖方同理）时，同方向表里的另一种写法清零，同一笔费用不会算两次。改动前就能用的写法（2022-04-29 以后的日期，或 2008-09-19 以后并显式给出 `fee_rate_buy`、`fee_rate_sell`）结果逐位不变，`test/test_ashare_fees.py` 守着。
